# 별빛 아카데미

12명이 함께 다니는 마법학교 생활 타이쿤 웹앱이에요. 학생이 되어 물약을 연구하고, 온실에서 약초를 키우고, 마법 생물을 돌보고, 시장에서 친구들과 거래해요.

- 화면: `public/index.html` (게임 전체가 이 파일 하나에 있어요, 폰 화면 390×844 기준)
- 그림: `public/art/` (픽셀 아트 PNG), 글꼴: `public/fonts/` (Galmuri, OFL)
- 저장과 실시간 접속: Firebase Realtime Database
- 로그인: 아이디(영어 3~16자) + 비밀번호(5자 이상). Firebase 이메일/비밀번호 인증을 아이디 형태로 감싸요 (`아이디@magionacademy.app`)
- 배포: `main` 브랜치에 푸시하면 GitHub Actions가 Firebase Hosting에 올려요

## 게임 흐름 (하루 단위)
| 화면 | 하는 일 |
|---|---|
| 홈 | 오늘의 주문 납품, 시간대 재료 채집, 학생 명부, 수업·기숙사로 이동 |
| 수업 | 하루 한 번, 칠판 문양을 순서대로 누르면 물약 레시피 힌트 |
| 연구실 | 재료 3개를 솥에 넣고 끓이기 (마력 5). 새 조합을 찾으면 물약 도감(12종)에 등록, 몇몇 물약은 마시면 효과 |
| 온실 | 씨앗 심기 → 물 주기(마력 1) → 자고 나면 자람 → 수확 |
| 사육장 | 양·유니콘·샐러맨더·드래곤에게 먹이 주기, 쓰다듬기, 애정이 차면 재료 |
| 기숙사 | 가구로 방 꾸미기 (아늑함이 높을수록 다음 날 마력 회복↑), 잠자고 내일로 |
| 시장 | (온라인) 물건 올리기·사기, 반 전체 협동 의뢰에 물약 기부 |

하루는 각자 따로 흘러가고(잠을 자면 다음 날), 시장과 협동 의뢰만 실시간으로 함께 써요.

## 처음 한 번만 하는 설정
1. Firebase 콘솔에서 **Authentication > 로그인 방법 > 이메일/비밀번호** 사용 설정
2. **Realtime Database > 데이터베이스 만들기** (잠금 모드로 시작, 규칙은 배포 때 `database.rules.json`으로 덮어써요)
3. **프로젝트 설정 > 내 앱 > 웹 앱 추가(`</>`)** → 나오는 `firebaseConfig`를 `public/firebase-config.js`에 붙여 넣기
4. `.firebaserc`의 `YOUR_PROJECT_ID`를 내 프로젝트 ID로 바꾸기
5. GitHub 저장소 시크릿 `FIREBASE_SERVICE_ACCOUNT`에 서비스 계정 JSON 넣기
6. `main`에 푸시하면 `https://<프로젝트ID>.web.app` 으로 배포돼요

`firebase-config.js`가 비어 있는 동안에는 **혼자 해 보기** 모드로만 들어갈 수 있어요 (이 기기 브라우저에만 저장).

## 내 컴퓨터에서 미리 보기
`public` 폴더를 아무 정적 서버로 열면 돼요. 예: `python3 -m http.server -d public`

## 데이터 구조
| 경로 | 내용 | 쓰기 권한 |
|---|---|---|
| `players/<uid>` | 학생 저장 데이터 (이름, 생김새, 골드, 마력, 가방, 온실, 생물, 가구…) | 본인 |
| `online/<uid>` | 지금 접속 중 표시 | 본인 |
| `market/<id>` | 시장 매물 (물건, 수량, 가격, 판매자, 구매자) | 판매자 / 구매자는 한 번만 |
| `coop/w<주>/<uid>` | 이번 주 협동 의뢰 기부량 | 본인 |
| `guest/<방주인 uid>/<id>` | 방명록 (한 줄, 선물, 받음 여부) | 손님은 새로 쓰기만 / 방 주인은 수정·삭제 |

## 기숙사 (하루 중 깨어 있는 시간대로 나눠요, 기숙사마다 3명)
| 기숙사 | 시간대 | 늘 받는 보너스 | 기숙사 시간 보너스 |

| Dewmorn | 5~10시 | 물 주기 마력 0 | 수확 +1 |
| Emberkiln | 10~16시 | 끓이기 마력 4 | 실패해도 재료 1개 돌려받기 |

## 물약 도감 (12종)
| 물약 | 레시피 | 비고 |
|---|---|---|
| 치유 | 약초 ×2 + 달빛 이슬 | |
| 화염 저항 | 보라 버섯 + 불도마뱀 비늘 + 달빛 이슬 | |
| 잠꾸러기 | 구름양 털 + 마력석 + 달빛 이슬 | |
| 성장 | 약초 + 보라 버섯 ×2 | 마시면 온실 식물 한 단계 성장 |
| 활력 | 마력석 + 불도마뱀 비늘 + 약초 | 마시면 마력 +15 |
| 포근 | 구름양 털 ×2 + 달빛 이슬 | 마시면 생물 애정 +1 |
| 반짝 | 약초 + 달빛 이슬 + 유니콘 갈기 | 공동 의뢰용 |
| 용기의 | 용 알 껍질 + 불도마뱀 비늘 + 마력석 | |
| 새벽빛 | 아침 안개 + 달빛 이슬 + 약초 | Dewmorn 시간(5~10시)에만 끓음 |

도감 4·8·12종에서 칭호가 올라가요: 견습 연금술사 → 연금술사 → 숙련 연금술사 → 별빛 연금술사.
