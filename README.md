# 별빛 아카데미

12명이 함께 다니는 마법학교 생활 타이쿤 웹앱이에요. 학생이 되어 물약을 연구하고, 온실에서 약초를 키우고, 마법 생물을 돌보고, 시장에서 친구들과 거래해요.

- 화면: `public/index.html` (게임 전체가 이 파일 하나에 있어요, 폰 화면 390×844 기준)
- 그림: `public/art/` (픽셀 아트 PNG), 글꼴: `public/fonts/` (Galmuri, OFL)
- 저장과 실시간 접속: Firebase Realtime Database
- 로그인: 아이디(영어 3~16자) + 비밀번호(5자 이상). Firebase 이메일/비밀번호 인증을 아이디 형태로 감싸요 (`아이디@magionacademy.app`)
- 배포: `main` 브랜치에 푸시하면 GitHub Actions가 Firebase Hosting에 올려요

## 게임 흐름 (하루 단위)
| 화면 | 하는 일 |
|---|---|
| 홈 | 오늘의 주문 납품, 행사 알림, 수업·기숙사로 이동 |
| 수업 | 하루 10번, 칠판 문양을 외워서 누르기 → 맞히면 지식 +1, 지식 3마다 레시피 힌트 |
| 연구실 | 재료 3개를 솥에 넣고 끓이기 (마력 5). 새 조합을 찾으면 물약 도감(100종)에 등록, 몇몇 물약은 마시면 효과 |
| 온실 | 씨앗 심기 → 물 주기(마력 1) → 자고 나면 자람 → 수확 |
| 사육장 | 양·유니콘·샐러맨더·드래곤에게 먹이 주기, 쓰다듬기, 애정이 차면 재료 |
| 기숙사 | 가구로 방 꾸미기 (아늑함이 높을수록 다음 날 마력 회복↑), 잠자고 내일로 |
| 시장 | (온라인) 물건 올리기·사기, 반 전체 협동 의뢰에 물약 기부 |

하루는 각자 따로 흘러가고(잠을 자면 다음 날), 시장과 협동 의뢰만 실시간으로 함께 써요.

## 처음 한 번만 하는 설정
1. Firebase 콘솔에서 **Authentication > 로그인 방법 > 이메일/비밀번호** 사용 설정
2. **Realtime Database > 데이터베이스 만들기** (잠금 모드로 시작, 규칙은 배포 때 `database.rules.json`으로 덮어써요)
3. **프로젝트 설정 > 내 앱 > 웹 앱 추가(`</>`)** → 나오는 `firebaseConfig`를 `public/firebase-config.js`에 붙여 넣기
4. `.firebaserc`의 `YOUR_PROJECT_ID`를 내 프로젝트 ID로 바꾸기
5. GitHub 저장소 시크릿 `FIREBASE_SERVICE_ACCOUNT`에 서비스 계정 JSON 넣기
6. `main`에 푸시하면 `https://<프로젝트ID>.web.app` 으로 배포돼요

`firebase-config.js`가 비어 있는 동안에는 **혼자 해 보기** 모드로만 들어갈 수 있어요 (이 기기 브라우저에만 저장).

## 내 컴퓨터에서 미리 보기
`public` 폴더를 아무 정적 서버로 열면 돼요. 예: `python3 -m http.server -d public`

| `players/<uid>` | 학생 저장 데이터 (이름, 생김새, 골드, 마력, 가방, 온실, 생물, 가구…) | 본인 |

시간은 각자 기기의 시계를 따라요. 기숙사가 없던 예전 학생은 다음 접속 때 기숙사를 고르는 화면이 나와요.

## 씨앗과 재료
- **씨앗 60종 = 식물 재료 60종.** 씨앗을 심어 키우면 같은 이름의 재료가 나와요 (예: 라벤더 → 라벤더, 마력 수정초 → 마력석).
- 씨앗은 7단계로 나뉘고, 지식 0 · 10 · 30 · 60 · 100 · 140 · 180부터 심을 수 있어요. 높은 단계일수록 오래 자라고(1~4일) 씨앗 값이 비싸요. 약초·월광초·보라 버섯은 무료예요.
- 사육장 재료 4종(구름양 털·불도마뱀 비늘·유니콘 갈기·용 알 껍질)까지 연구실 재료는 모두 64종이에요.
- 화단은 6칸에서 300G씩 9칸까지 늘릴 수 있어요.
- 전체 목록은 `public/index.html`의 `SEED_LIST` 표, 아이콘은 `public/art/plants.png`(10×6칸)

## 물약 도감 (100종)
- 기존 12종은 기본 재료 레시피 그대로예요. 새 88종은 씨앗 단계에 맞춰 식물 재료(+가끔 생물 재료)로 만들어요. 쉬운 물약은 1단계 식물, 어려운 물약은 높은 단계 식물이 들어가요.
- 물약마다 색이 모두 다르고, 병 모양 10가지 × 무늬 10가지로 그림도 모두 달라요 (`public/art/potions.png`, 10×10칸).
- 전체 목록(이름·레시피·보상·색)은 `public/index.html`의 `POTION_LIST` 표에 있어요.
- 특별한 물약: 성장·활력·포근(마시면 효과), 반짝(공동 의뢰), 새벽빛·한낮의·노을·달그림자(그 기숙사 시간에만 끓음), 별빛(100번째, 소원 민들레 + 영혼 연꽃 + 용 알 껍질)

## 수업과 지식
- 하루 10번. 칠판 문양이 잠깐 보였다가 가려지면, 본 순서대로 눌러요. 틀려도 1번은 쓴 걸로 쳐요.
- 맞히면 지식 +1. 지식 3마다 다음 레시피 힌트가 열려요 (쉬운 물약부터). 지식 30마다 문양이 하나씩 길어져요 (4개 → 최대 7개).

## 옷 가게 (마을의 「옷 가게」 문, 캐릭터 꾸미기에서도 열려요)
- 교복은 처음부터 다 입을 수 있어요. 사복(후드티·니트·져지·야구잠바·블루종·정비공·수트·세일러복·가쿠란·패딩 등 상의 49, 바지·치마 18, 신발 6), 잠옷(동물 잠옷 등 상의 8·바지 3·슬리퍼), 모자 14(비니·동물 비니·동물 귀·마녀 모자…)는 골드로 사요 (40~260G).
- 입어 보고 「사서 입기」를 누르면 사요. 산 옷은 캐릭터 꾸미기 「옷」 탭에서 언제든 갈아입어요. 사복·잠옷 색은 자유롭게 골라요.
- 저장: `players/<uid>/closet` = { '부위:부품id': 1 }. 옷 그림은 `tools/iso/lpc/build_lpc.py`의 `SHOP` 표.

## 학교 행사 (다 같이 같은 시간에)
| 행사 | 언제 | 하는 일 | 보상 |
|---|---|---|---|
| 드래곤의 방문 | 토·일 20:00~20:20 | 물약을 바쳐 드래곤의 기분을 40점까지 채워요 | 바친 학생 모두 용 알 껍질 ×2 + 150G |

- 시간은 각자 기기 시계 기준이에요. 행사가 끝나고 60분 동안은 결과와 보상을 볼 수 있어요.
- **미리보기:** 주소 뒤에 `?event=dragon`을 붙이면 지금 바로 열려요. 기록은 `test` 칸에 따로 쌓여서 진짜 행사와 섞이지 않아요.
- 데이터: `events/dragon/<행사키>/<uid>` = 바친 점수

## 주간 쪽지시험
- 수업 화면 아래 **이번 주 쪽지시험**에서 일주일에 한 번 볼 수 있어요. 중간에 나가도 본 걸로 쳐요.
- 10문제, 문제당 20초. 아는 레시피(최대 5문제), 기숙사 시간·보너스, 생물 재료, 시간대 물약에서 나와요.
- 보상: 60점부터 장학금(점수×2G), 80점부터 귀한 재료 ×2, 100점이면 용 알 껍질 ×1
- 기숙사 평균 점수가 별로 보여요. 데이터: `exam/<주>/<uid>` = 점수

## 생물 키우기
- **알 → 아기 → 어른:** 배부름 2칸 이상으로 잔 날마다 하루씩 자라서, 3일이면 어른이 돼요. 어른은 재료를 2개(아기는 1개) 줘요.
- **짝꿍 맺기:** 어른 둘을 골라 하루 한 번(마력 10) 알을 얻어요. 사육장에서 내 생물끼리, 친구 방에서 친구 생물과(친구마다 하루 한 번) 맺을 수 있어요. 알은 2일 자면 깨어나요.
- **색 변종:** 노을빛·바다빛·황금빛. 부모 색을 반쯤 물려받고, 아니면 가끔(같은 종 30%, 다른 종 15%) 새로 나와요. 변종은 재료를 1개 더 줘요.
- 우리는 6칸까지. 어른과 작별하면 칸이 비고 재료 1개와 30G를 받아요.
- 예전 학생의 생물 4마리는 이미 키우던 아이들이라 어른으로 시작해요. 새 학생은 아기(1일차)로 시작해요.

친구 방에는 방명록의 이름이나 시장의 '○○의 가게 · 방 구경'을 눌러서 놀러 가요.
