- [ ] **탐사 균형 맞추기**: 걷는 속도·갈림길(8~13%)·몬스터(12~24초)·돌발 상황(22~40초) 간격과 피해 15%는 임시 수치예요. 직접 해 보고 조정.

- [ ] **UI 간결화 2차**: 지도 화면·NPC 대화 창·전투 화면 점검, 오늘의 정보 화면을 없앨지 결정, 가방 「선물」 탭 유지 여부.
- [ ] **눌러서 쓰던 분위기 소품**: 이야기나 작은 기능을 붙일 소품 고르기 (허용 목록 `ACT_REAL`에 추가하면 다시 눌려요).
