# 이벤트 1 「용의 알 지키기」 (실시간 디펜스)

## 확정된 규칙
- 평소에는 학생에게 아무것도 안 보여요. 관리자가 「이벤트 열기」를 눌러야 오른쪽 위에 버튼이 생기고, 「이벤트 닫기」를 누르면 사라져요.
- 맵 3곳 (숲길 → 둥지 입구 → 둥지 앞), 곳마다 서는 자리 6곳. 몬스터는 길을 따라 걸어가서 길 끝에서 다음 장소로 넘어가고, 둥지 앞을 지나면 알이 맞아요.
- 웨이브 15개: 1차 (1·2 일반 / 3·4 정예 / 5 보스) → 2차 (6·7 / 8·9 / 10) → 3차 (11·12 / 13·14 / 15 최종 보스). 뒤로 갈수록 세져요.
- 알 3개 (불·물·숲의 용). 지켜 내면 부화해서 학교에 살게 돼요 (혜택은 5단계: 한 번 받으면 2시간, 하루 2회).
- 자리는 웨이브 시작 전(준비·쉬는 시간)에만 고를 수 있어요. 직업은 각자 정한 직업.
- 스킬은 쿨타임이 차면 쓰고, 이벤트 골드로 항목(공격력/사거리/쿨타임, 치유량/범위/쿨타임)을 따로 올려요 (최대 Lv5, 빠듯하게).

## 구조
- `public/td.js` 계산만 하는 엔진 (node에서도 돌아가요). `tools/td_sim.js` 균형 시뮬: `node tools/td_sim.js <팀당 인원> <판 수> <체력 배율>`
- `public/tdmap.js` 지도 그림 (도트, 한 번만 그려서 늘려 써요)
- DB `defense/ctl`(열림·단계, 관리자) · `defense/st`(그림용 스냅샷 4Hz, 관리자) · `defense/pick/<uid>`(내 자리, 본인)
- 계산은 **관리자 화면이 켜져 있는 동안** 관리자 기기에서 해요. 꺼지면 학생 화면에 「잠시 멈췄어요」가 떠요.

## 진행 단계
1. ✅ 엔진 + 균형 시뮬
2. ✅ 지도 3곳 · 몬스터 이동 · 자리 고르기 · 관리자 열기/닫기/웨이브 시작
3. ✅ 스킬 단추(직업 스킬 그림·이름) · 쿨타임 표시 · 직접 누르기 · 자동 켜기/끄기 · 기본 공격은 늘 자동 · 사거리 원
4. ✅ 이벤트 골드 표시 · 스킬 올리기 화면 (항목 따로, Lv5, 200/350/550/800G)
5. ⬜ 결과 · 용 혜택 (2시간 · 하루 2회) · 보상 정산
