# 이벤트 1 「용의 알 지키기」 (실시간 디펜스)

## 확정된 규칙
- 평소에는 학생에게 아무것도 안 보여요. 관리자가 「이벤트 열기」를 눌러야 오른쪽 위에 버튼이 생기고, 「이벤트 닫기」를 누르면 사라져요.
- 맵 3곳 (숲길 → 둥지 입구 → 둥지 앞), 곳마다 서는 자리 6곳. 몬스터는 길을 따라 걸어가서 길 끝에서 다음 장소로 넘어가고, 둥지 앞을 지나면 알이 맞아요.
- 웨이브 15개: 1차 (1·2 일반 / 3·4 정예 / 5 보스) → 2차 (6·7 / 8·9 / 10) → 3차 (11·12 / 13·14 / 15 최종 보스). 뒤로 갈수록 세져요.
- 알 3개 (불·물·숲의 용). 지켜 내면 부화해서 학교에 살게 돼요 (혜택은 5단계: 한 번 받으면 2시간, 하루 2회).
- 자리는 웨이브 시작 전(준비·쉬는 시간)에만 고를 수 있어요. 직업은 탐사에서 고른 직업 그대로(바꿀 수 없어요).
- 웨이브는 **학생들이 자리를 정하고 모두 「시작」을 눌러야** 와요 (관리자는 연출만 송출 · 강제 시작 단추는 있어요). 기본 공격은 늘 자동, 어느 자리든 가장 가까운 길에서부터 사거리를 재서 길 가까이에 닿아요.
- 스킬은 쿨타임이 차면 쓰고, 이벤트 골드로 항목(공격력/사거리/쿨타임, 치유량/범위/쿨타임)을 따로 올려요 (최대 Lv5, 빠듯하게).

## 연출
- **시작**: 관리자가 「시작 송출」을 누르면 모든 학생 화면에서 연출이 나와요 (레오·스텔라: 신성한 용 알이 곧 부화하는데 숲의 몬스터들이 노린다, 도와 달라). 약 26초 뒤 첫 웨이브가 시작돼요. 건너뛰기 가능.
- **끝**: 알을 지켰으면 알이 흔들리고 금이 가고 번쩍 하며 아기 용(화륵이·졸졸이·무럭이)이 태어나요. 깨진 알은 회색으로 남고, 전부 깨졌으면 아쉬운 연출이에요.
- 아기 용 그림: `tools/iso/dragons.py` → `public/art/dragons.png` (32칸 × 4동작 × 3종)

## 용의 동굴 (이벤트가 끝난 뒤)
- 학교 북쪽에 기둥 문(30,14)이 있고, 지켜 낸 용이 한 마리라도 있으면 열려요. 안은 별도 맵 「용의 동굴」(`tools/iso/dcave.py`).
- 지켜 낸 알은 아기 용(화륵이·졸졸이·무럭이)으로 둥지에 살고, 깨진 알 자리에는 깨진 알껍데기가 놓여요.
- 용에게 말을 걸면 「크르릉…」하고, 가호를 받을 수 있어요: **2시간, 하루 2번** (자정에 초기화). 불의 용 = 탐사 공격 +5% · 물의 용 = 마력 회복 +10% (탐사·쉬기) · 숲의 용 = 채집·수확 +10% (10% 확률로 하나 더) · 경험치 +3%.
- 결과는 `defense/res`에 남아요 (이벤트를 닫아도 유지, 「처음으로」·전체 초기화 때 지워져요).
- 지도 다시 만들기: `python3 tools/iso/dcave.py && python3 tools/iso/splice_maps.py` (world.js는 손으로 고친 부분이 있어 MAPS 줄만 바꿔요)

## 몬스터 흐름 · 공격
- 숲길에서 못 잡은 몬스터는 둥지 입구로, 거기서도 못 잡으면 둥지 앞으로 가요. 둥지 앞 길 끝에 닿으면 **알을 때려요** (잡을 때까지 계속). 알 3개 체력이 모두 0이 되면 끝이에요.
- 기본 공격: 직업 상관없이 2초에 한 번, 사거리 같음(자리에서 가장 가까운 길 기준), 작은 콩알. 스킬 2개는 이벤트 전용이고 직업·레벨·습득과 상관없이 모두 똑같아요 (치유·버프 없음): ① 일격 = 가까운 한 명에게 센 공격 ② 번개비 = 넓은 범위 모두에게 약한 공격. 쿨타임만 차면 누구나 써요.
- 6명(팀당 2명)으로 시험: 도구로 AI 봇 시뮬(`tools/td_sim.js`) + 브라우저 6개 창으로 자리·준비·웨이브·스킬을 돌려 봤어요.

## 구조
- `public/td.js` 계산만 하는 엔진 (node에서도 돌아가요). `tools/td_sim.js` 균형 시뮬: `node tools/td_sim.js <팀당 인원> <판 수> <체력 배율>`
- `public/tdmap.js` 지도 그림 (도트, 한 번만 그려서 늘려 써요)
- DB `defense/ctl`(열림·단계, 관리자) · `defense/st`(그림용 스냅샷 4Hz, 관리자) · `defense/pick/<uid>`(내 자리, 본인)
- 계산은 **관리자 화면이 켜져 있는 동안** 관리자 기기에서 해요. 꺼지면 학생 화면에 「잠시 멈췄어요」가 떠요.

## 진행 단계
1. ✅ 엔진 + 균형 시뮬
2. ✅ 지도 3곳 · 몬스터 이동 · 자리 고르기 · 관리자 열기/닫기/웨이브 시작
3. ✅ 스킬 단추(직업 스킬 그림·이름) · 쿨타임 표시 · 직접 누르기 · 자동 켜기/끄기 · 기본 공격은 늘 자동 · 사거리 원
4. ✅ 이벤트 골드 표시 · 스킬 올리기 화면 (항목 따로, Lv5, 200/350/550/800G)
5. ⬜ 결과 · 용 혜택 (2시간 · 하루 2회) · 보상 정산

## 서버 계산 (관리자 화면을 안 켜 둬도 됨)
- `functions/` (Cloud Functions 2세대, asia-southeast1). 관리자 화면이 `defense/run` 에 쓰면 `dfrun` 이 켜져서 `defense/ctl·st` 를 쓰고 학생 명령(`cmd`)과 관리자 버튼(`adm`)을 받아요.
- 한 번에 최대 9분이라 7분 30초쯤에 스스로 `run` 을 다시 써서 다음 실행에 넘겨요(진행은 `defense/host` 에 1초마다 저장, `defense/lock` 으로 한 곳만 계산).
- 계산 코드는 `public/td.js` 를 배포 때 `functions/td.js` 로 복사해 같이 써요(firebase.json predeploy).
- 서버가 안 켜지면 관리자 카드의 「이 화면에서 직접 진행 (예비)」로 예전 방식(관리자 화면 계산)을 쓸 수 있어요.
