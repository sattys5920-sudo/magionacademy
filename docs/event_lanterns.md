# 이벤트 「유령 등불 찾기」 (하루 이벤트)
- 반 전체가 **유령 등불 60개**를 모아요. 한 사람은 **최대 10개**까지, 10개를 채우면 더는 안 나와요.
- 얻는 법: 이벤트 중 낚시(건진 물고기)·채집·탐사 끝에서 **5% 확률로 저절로 모여요**(줍는 동작 없음). 관리자가 확률을 5·10·15%로 조절.
- 모은 개수가 늘수록 학교의 가로등·창문 불빛이 점점 밝아져요(`World.lampBoost` 0~1 = 모은 수/60, 바깥 지도만).
- 시작 연출(아울라 + 꼬마 유령)은 이벤트가 열린 뒤 처음 접속할 때 한 번, 60개가 차면 끝 연출 뒤 장식 고르기.
- **유령 등불 장식 12색**: 학생마다 하나, **색마다 한 사람만**(먼저 고른 사람 것). 방 가구 `ghostlamp0~11`(이벤트 가구 `ev:1`, 상점에는 안 나옴). 색: 빨강·주황·노랑·연두·초록·민트·하늘·파랑·남색·보라·자홍·분홍.
- 데이터: `lantern/ctl {open,id,rate}`, `lantern/cnt/<uid>` (0~10), `lantern/color/<0~11>` = 고른 사람 (database.rules.json).
- 그림: 꼬마 유령 초상화 5표정 `ev4_ghost.png`, 찾을 등불 `ev4_lantern.png`, 방 장식 `ev4_lamp_00~11.png`, 연출 배경 `ev4_school_dim/lit.png`. 만드는 스크립트: `tools/iso/ev4_art.py`, `tools/ev4_school_shot.js`(연출 배경: 실제 학교 화면을 찍어요), `ev4_furn.py`(가구 도감에 더함, 여러 번 돌려도 같음). 원본 그림은 `tools/iso/ev4_src/`.
