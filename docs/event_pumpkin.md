# 이벤트 「호박밭 같이 가꾸기」 (하루 이벤트, 전투 없음)
- 장소: 학교 앞 호박밭(campus 22,88, 스트로 허수아비 옆). 반 전체(12명 기준)가 마법 호박을 5단계로 키워요: 씨앗 0% · 새싹 20% · 덩굴 45% · 꽃 70% · 거대 호박 100%. 목표 점수 600(`pumpkin/ctl.goal`).
- 돌보기: 물 주기 +2(1시간마다), 말 걸어 주기 +3(2시간마다), 거름 주기(약초 +6 흔함 · 달빛 이슬 +10 보통 · 마나석 +20 귀함, **재료마다 따로 10번까지**). 관리자가 속도 ×1·×2·×3. 점수는 `pumpkin/pts/<uid>`, 물 준 횟수는 `pumpkin/w/<uid>`.
- 단계 보상(모두에게, 자동): 새싹 씨앗 쿠폰 2장(심을 때 값 대신) · 덩굴 스킬 포인트 1 · 꽃 마나석 1개.
- 완성 보상: 물을 한 번이라도 준 학생 500골드 + 기여 상위 5명은 1000골드와 마나석 1개 더(`me.pk.res`).
- 완성 뒤: 거대 호박(웃는 얼굴, 밤에 은은히 빛남)이 호박밭에 남아요. 누르면 하루 한 번 **호박의 축복**(탐사 경험치 +10%, 3시간, `me.buffs.pump`). 호박 장식 가구·기숙사 앞 호박은 없어요.
- 호박 그림: 게임 속 호박과 같은 도트(`public/art/ev5_pumpkin.png` 5단계, `tools/iso/ev5_prev.py`). 월드 소품은 `World.setProps(지도, 목록)` / `World.onProp(id)`.
