# 이벤트 2 「유령 선장의 보물 지도」 (하루 이벤트, 보스 없음)
- 지도 그림을 10×5 = 50조각 직소 퍼즐로 잘라서, 반 전체가 하나의 보드에 **드래그로** 맞춰요 (그림: `tools/iso/ev2_map.py` → `public/art/ev2_map.png`, `ev2_pieces.png`).
- 조각 얻기: 이벤트가 열려 있는 동안 낚시(건진 물고기 12%)·채집(12%)·탐사 끝(60%)에서 확률로 나와요. 관리자가 확률 ×1·×2·×3으로 조절. 한 사람이 보드에 안 놓은 조각은 8개까지 가질 수 있고, 조각은 반 전체에서 겹치지 않아요(`puzzle/own/<번호>` 트랜잭션).
- 맞추기: 조각을 끌어다 맞는 자리 근처(13칸 안)에 놓으면 붙어요 → `puzzle/board/<번호>` 에 기록. 틀린 자리는 튕겨 나와요.
- 시작 연출: 밤 호수에 유령선이 떠오르고 해골 선장(해적 모자)이 아울라와 이야기해요 (그림 `tools/iso/ev2_scene.py`).
- 완성(50/50): 모두의 화면에 완성 연출이 나온 뒤 **보물 상자 12개**를 반 전체가 나눠 가져요: 한 사람이 한 번만 고를 수 있고, 먼저 고른 사람 것이 돼서 다른 사람은 못 골라요(`puzzle/chest/<번호>`, 내용은 이벤트마다 섞여 있어 모두에게 같아요).
  [골드/마나석/스킬 포인트] 300·3·2 · 400·3·2 · 500·3·1 · 600·3·1 · 700·2·1 · 800·1·1 · 900·0·1 · 1000~1400·0·0 (돈이 적은 상자에 마나석·스킬 포인트가 얹혀요). 받은 기록은 `me.pz`.
- 관리자: 이벤트 열기·닫기·처음으로·확률. 데이터 `puzzle/ctl {open,id,rate}`, `puzzle/own`, `puzzle/board` (database.rules.json 참고).
