# 이벤트 「별 보는 밤」

스텔라와 함께 별을 하나씩 켜서 별자리를 완성하는 협동 이벤트예요 (2주 4번, 별자리 5개 중 4개 사용).

## 흐름
1. **모이기**(gather): 학생에게 「스텔라가 같이 별을 보자고 해요!」 팝업 → [같이 볼래요]로 참가. 관리자 화면도 같은 창이 자동으로 떠요.
2. **별 나눠 주기**(assign, 10초): 참가 순서대로 별을 하나씩 (회차마다 시작 별을 3칸씩 밀어요). 남는 별은 스텔라 몫.
3. **별 켜기**(light, 기본 60초): 자기 별(반짝이는 고리)을 눌러 켜요. 스텔라가 남은 별을, 시간이 지나면 못 켠 별도 대신 켜요.
4. **하늘 보기**(sky): 선이 순서대로 0.6초씩 이어져요 → 윤곽 · 별자리 이름.
5. **이야기**(done): 별자리 이야기 · 버프 안내 · 마무리 대사가 6초 간격으로 이어져요. 그동안 참가자에게 버프가 지급돼요.

진행은 **관리자 화면이 열려 있어야** 자동으로 넘어가요(용 알 이벤트와 같은 방식). 모든 접속자는 서버 시각 기준으로 같은 순간을 봐요.

## 관리자 (이벤트 탭 → 「별 보는 밤」)
별자리 고르기(사용함 표시) · 지금 열기 · 미리 보기(회차 선택) · 예약(날짜·시각, 여러 개) · [별 나눠 주기][하늘 보기 시작][강제 완성][이벤트 끝내기] · 같이 보기 · 설정(버프 시간·별 켜기 제한·모이기 기다림).

## 데이터
- `public/data/events/stargazing/constellations.json` 별자리 5개(좌표·선 순서·버프 수치). 만들기·검사: `python3 tools/stargaze/make_data.py`
- `.../dialogue/<별자리>.json`, `common.json` 스텔라 대사. 만들기·검사: `python3 tools/stargaze/make_dialogue.py`
- 그림: `public/stargaze_sky.js`(하늘 그리기) · `public/art/stargaze_horizon_390/720.png`(`tools/stargaze/horizon.py`)
- DB: `stargaze/ctl` (admin 전용) · `join/<uid>` · `lit/<별>` · `cfg` · `sched` · `hist` (`database.rules.json`)

## 버프 (같은 종류는 새로 받으면 바뀜, 실제 시간 기준)
| 별자리 | 버프 | 반영된 효과 |
|---|---|---|
| 호박 수레자리 | 풍작의 별빛 | 온실 수확량 +20% · 작물 성장 +10% |
| 마녀 빗자루자리 | 밤바람의 별빛 | 이동 속도 +15% · 물 주기 마력 소모 −20%(0이 될 확률) |
| 졸린 부엉이자리 | 지혜의 별빛 | 요리 별점이 오를 확률 +15% · 탐사 경험치 +15% |
| 방울 고양이자리 | 방울 소리의 별빛 | 낚시 희귀 물고기 +20% · 선물 호감도 +10% |
| 열두 친구자리 | 열두 친구의 별빛 | (수치만 데이터에 있고 아직 적용 안 함) |
