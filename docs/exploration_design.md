# 탐사 시스템 설계서 (초안 v1)

> **구현 현황 (1단계 배포됨)**: 혼자 탐사 + 동료 2명 자동 전투, 직업 3종(전사·백마법사·흑마법사) 스킬 5개씩(레벨로 열림), 지역 1곳(달빛 숲길 20분), 레벨 상한 50·경험치 곡선, 하루 5회·입장 50G, 갈림길(투표 없음), 석상·캠프·상자. 아직 **없는 것**: 실제 플레이어 협동·방·투표, 관리자 직업 선택 창, 스탯 포인트·스킬 트리, 나머지 9직업·3지역, 이펙트 연출 고도화. 코드는 `public/index.html`의 「탐사」 부분(함수 이름이 `x`로 시작).

파판4식 시간 게이지 전투 + 갈림길 탐사. 실제 플레이어 1~5명 협동. 이 문서는 구현 전에 정해 둘 것들을 모은 거예요.
✅ 확정(사용자 답변) · 🟡 제안(확인 필요) · ❓ 남은 질문

## 1. 큰 틀 ✅
| 항목 | 결정 |
|---|---|
| 파티 | 실제 플레이어 1~5명 협동. 플레이어가 **방을 만들고 초대** |
| 직업 | 12종. **처음 한 번 고르면 고정** (캐릭터 하나 = 직업 하나). 같은 직업 중복 가능 |
| 직업 고르는 때 | 탐사가 처음 열릴 때 관리자가 「직업 고르기」 창을 송출 → 각 플레이어가 한 번 선택 |
| 전투 | 액티브 타임(시간 게이지). 각자 게이지가 차면 행동 |
| 열림 | 상시 열림 |
| 입장 제한 | **인당 하루 5회** (파티원으로 참여해도 1회 소모) + 입장 비용 🟡 |
| 타이머 | **현실 시간, 앱을 닫아도 흐름**. 시간이 끝나면 탐사 종료 → 마을로 |
| 진행 | 갈림길 노드 선택. 노드마다 진행률(%)이 오름. **길은 파티원 투표로 정해요** (제한시간 15초, 과반수, 동률이면 방장 표) |
| 입장 비용 | **각자 자기 몫을 내요** (방장이 대신 내지 않음) |
| 이탈 | 접속이 끊기거나 자리를 비우면 **자동 전투(AI)**로 이어 감. 돌아오면 다시 직접 조작 |
| 전멸 | 그 탐사에서 얻은 것 **전부 잃음** (마을로 복귀) |
| 난이도/시간 | **20분 ~ 1시간** |

탐사 종료 규칙 🟡
- 100% 달성: 클리어 보너스 + 얻은 것 전부
- 도중에 끝내기(철수): 얻은 것 전부 (경험치·보상 유지)
- 시간 만료: 얻은 것 전부 유지, 클리어 보너스만 없음
- 전멸: 얻은 것 전부 잃음 (입장 비용·횟수는 돌아오지 않음)

## 2. 탐사 흐름 🟡
1. 방장이 **방 만들기** → 지역·난이도 고르기 → 친구 초대(방 목록 + 초대 알림, 놀이 게시판과 같은 방식)
2. 모두 준비(직업 확인) → 방장이 **출발**: 입장 비용 지불, 횟수 1 소모, 타이머 시작
3. **지도 화면**: 다음 노드 2~3개 중 하나를 **투표**로 고름 (15초, 과반수. 동률이면 방장 표. 투표 안 한 사람은 기권, 혼자면 바로 결정)
4. 노드 도착 → 이벤트 처리 → 진행률 상승 → 다음 노드
5. 마지막 구간에 **보스**. 보스를 쓰러뜨리면 100%
6. 종료 → 마을 복귀, 결과 창(얻은 것·경험치·사망 여부)

### 진행률과 노드
- 길은 한 번 탐사할 때 시드로 만든 그래프 (층 6~9개, 층마다 노드 2~3개)
- 노드 종류와 진행률 증가량

| 노드 | 증가 | 내용 |
|---|---|---|
| 전투 | +6~9% | 일반 몬스터 1~4마리 |
| 정예 전투 | +10~14% | 강한 몬스터, 보상 큼 |
| 캠프파이어 | +4% | 체력·마력 절반 회복 + 약한 버프 선택 |
| 고대 석상 | +5% | 선택지: 기도 / 조사 / 부수기 → 버프·희귀 아이템·저주 (위험과 보상) |
| 보물상자 | +4% | 골드, 재료, 가끔 희귀품. 가끔 미믹(전투) |
| 샘 | +3% | 체력 회복 |
| 수상한 상인 | +3% | 골드로 소모품 구매 (물약 등) |
| 미지 | +5% | 위 중 하나가 무작위로 |
| 보스 | → 100% | 마지막 노드 (진행률 85~90% 이후에만 보임) |

- 진행률 합이 100%에 모자라도 보스는 마지막에 항상 나옴: 보스에 도달하면 남은 %가 보스 승리 보상으로 채워짐
- 시간 압박: 노드마다 현실 시간으로 평균 2~4분 쓰도록 길이 조절 (전투 길이, 이벤트 선택 시간)

### 탐사 지역 4곳 🟡 (난이도 4단계)
| 지역 | 난이도 | 제한시간 | 분위기 |
|---|---|---|---|
| 달빛 숲길 | 쉬움 | 20분 | 안개 낀 숲, 작은 몬스터 |
| 무너진 지하 묘지 | 보통 | 30분 | 해골·유령 |
| 안개 호수 동굴 | 어려움 | 45분 | 물가 괴물, 함정 |
| 호박달 고대 신전 | 악몽 | 60분 | 고대 수호자, 최종 보스 |

- 난이도마다 나오는 몬스터, 석상 종류, 상자 등급, 보상이 달라요 (아래 표)

## 3. 캐릭터 · 레벨 · 스탯 · 스킬 🟡

### 레벨 ✅ 상한 50
- 레벨 상한 **50**. 레벨 L→L+1에 필요한 경험치 = `14 × L^2.3` (10단위로 반올림). 레벨이 높을수록 훨씬 많이 필요해요.

| 레벨 | 다음 레벨까지 | 누적 경험치 | 열심히 하는 사람 기준 (하루 5회) |
|---|---|---|---|
| 5 | 약 330 | 600 | 1~2일 |
| 10 | 약 1,800 | 7,100 | 약 5일 |
| 20 | 약 8,900 | 77,000 | 약 3주 |
| 30 | 약 25,000 | 300,000 | 약 6주 |
| 40 | 약 56,000 | 790,000 | 약 3개월 |
| 50 (상한) | — | 1,660,000 | 약 4~5개월 |

- 하루 5회 모두 **자기 레벨에 맞는 지역**을 클리어했다고 가정한 값이에요. 쉬운 지역만 돌면 훨씬 느려요.
- 경험치는 전투 승리·이벤트·클리어 보너스에서 얻어요. 파티원에게 똑같이 (사망/AI 대행 중이어도).
- **레벨 차 보정**: 몬스터보다 내 레벨이 5 이상 높으면 경험치 ×0.5, 9 이상 높으면 ×0.2 (쉬운 지역 반복으로 올리기 방지). 몬스터가 3 이상 높으면 ×1.2 (최대 ×1.5).
- 지역별 몬스터 레벨: 쉬움 1~12 · 보통 10~24 · 어려움 22~38 · 악몽 36~50 (최종 보스 50). 지역별 클리어 경험치 기준(파티 보정 전): 쉬움 300 · 보통 900 · 어려움 2,500 · 악몽 6,000.
- 레벨 50에서는 경험치가 더 쌓여도 레벨은 안 올라가요 (대신 골드 보상 +20%, 칭호 같은 보상 🟡).
- 레벨업 보상: **스탯 포인트 3, 스킬 포인트 1** → 상한까지 스탯 147, 스킬 49포인트.

### 스탯 5종
| 스탯 | 뜻 | 쓰임 |
|---|---|---|
| 체력 (HP) | 최대 체력 | 1포인트 = 최대 체력 +12 |
| 공격력 (ATK) | 물리 피해 | 전사·도적·기사·기공사 중심 |
| 마법공격력 (MAG) | 마법 피해, 마력 | 흑마법사·소환사·연금술사 중심, 최대 마력에도 영향 |
| 치유력 (HEAL) | 회복량, 보호막 | 힐러 3종 중심 |
| 속도 (SPD) | 게이지 차는 속도 | 행동 빈도, 시간술사 효과의 기본 |

- 방어력(DEF)은 직업 기본값 + 스킬로 정해지고, 포인트로 올리지 않아요 (스탯이 많으면 복잡해서)
- 직업별 기본 스탯과 성장 보정 (예: 전사 HP·ATK 높음, 흑마법사 HP 낮고 MAG 높음). 상세 표는 구현 때 데이터로
- 스탯 포인트는 언제든 **초기화 가능** (골드), 한 직업으로 고정이라 분배 실수를 되돌릴 수 있게

### 스킬 트리 규칙
- 직업마다 스킬 **15개** = 줄기 3개 × 5개
- 스킬마다 레벨 1~4. **한 스킬을 4레벨(만렙)까지 올려야 같은 줄기의 다음 스킬이 열려요**
- 줄기 4번째 스킬부터는 다른 줄기의 2번째 스킬 레벨 2 이상이 필요 🟡 (한 줄기만 파지 못하게)
- 레벨 50까지 스킬 포인트가 총 49. 15개 × 4레벨 = 60 필요 → 다 못 찍으니 **끝까지 가도 선택이 의미 있어요** (보통 2줄기를 깊게 + 1줄기 일부)
- 첫 스킬 1개는 직업을 고르면 기본으로 습득 (이후 레벨 1 포인트부터 트리)
- 패시브(P)와 액티브(A)가 섞여 있고, 액티브는 마력(MP)을 써요. 마력은 시간이 지나면 조금씩 참

### 스킬 이펙트 (공용 연출 12종을 조합)
`베기` `충격` `불꽃` `얼음` `번개` `성광` `암흑` `독` `치유` `강화` `약화` `소환`
- 한 스킬 = 연출 1~2종 + 숫자(배율, 대상, 지속). 연출은 캔버스에서 작은 스프라이트·파티클로 그려요

## 4. 직업 12종 · 스킬 15개 🟡
(A = 액티브, P = 패시브 / 괄호는 한 줄 설명)

### 딜러
**전사** — 줄기: 차지 · 근성 · 도끼술
- 차지: 강타 / 차지 베기(준비 후 큰 피해) / 대지 가르기(광역 소) / 분노의 일격 / 극한 차지(준비 시간이 길수록 피해↑)
- 근성: 단단한 피부(P 피해 감소) / 되받아치기 / 불굴(P 쓰러질 때 1회 버팀) / 피의 갈증(P 흡혈) / 전장의 포효(자신 공격↑)
- 도끼술: 회전 베기 / 투척 도끼 / 파쇄(방어 감소) / 학살자(체력 낮은 적 추가 피해) / 폭풍 도끼

**흑마법사** — 줄기: 화염 · 냉기와 번개 · 암흑
- 화염: 불꽃탄 / 화염구(광역) / 불씨(지속 화상) / 지옥불 / 메테오(큰 광역)
- 냉기와 번개: 서리 화살 / 얼음 창 / 번개 / 연쇄 번개 / 눈보라(광역 감속)
- 암흑: 마력 흡수 / 약점 간파(속성 약점 노출) / 암흑 구체 / 공허의 손 / 마력 폭주(P 마력 소모↑ 피해↑)

**도적** — 줄기: 연속 · 급소 · 그림자
- 연속: 찌르기 / 이중 베기 / 칼춤(여러 번 타격) / 연환 / 난도질
- 급소: 약점 노리기(치명타↑) / 출혈 / 급소 찌르기 / 처형자(P 약화된 적 추가 피해) / 피 웅덩이(출혈 폭발)
- 그림자: 재빠른 발(P 속도↑) / 연막 / 그림자 걸음(회피) / 훔치기(보상 추가) / 뒤잡기

### 서포터
**음유시인** — 줄기: 전투가 · 안식가 · 풍자
- 전투가: 용기의 노래(공격↑ 지속형) / 승리의 행진 / 전장의 북소리 / 불꽃의 변주 / 영웅의 서사시(오래 유지할수록 ↑)
- 안식가: 수호의 노래(방어↑) / 자장가(체력 천천히 회복) / 평온의 선율 / 되살림의 화음 / 별빛 합창
- 풍자: 불협화음(적 약화) / 도발의 곡 / 흥겨운 춤(속도↑) / 앙코르(직전 노래 연장) / 대합창

**시간술사** — 줄기: 가속 · 감속 · 시간 조작
- 가속: 서두르기(대상 속도↑) / 연속 가속 / 시간 도약(즉시 행동) / 가속 영역 / 질주
- 감속: 늦추기(적 속도↓) / 정지(잠깐 정지) / 늪 같은 시간 / 시간 정체 / 영원한 정오
- 시간 조작: 되감기(피해 되돌림) / 예지(회피↑) / 시계 소환(턴 지연) / 시간 균열 / 시간 정지(파티 전체 연속 행동)

**연금술사** — 줄기: 약화 · 혼합 · 폭발물
- 약화: 산성 플라스크(방어↓) / 독 병 / 불안정 용액(저항↓) / 부식 / 약점 증폭
- 혼합: 응급 물약 / 마력 물약 / 혼합 약(상황별 효과) / 엘릭서 / 변이약
- 폭발물: 폭죽탄 / 점착 폭탄 / 연쇄 반응 / 황금 폭발 / 연금 대폭발

### 힐러
**백마법사** — 줄기: 회복 · 부활 · 성광
- 회복: 치유 / 큰 치유 / 집단 치유 / 신성한 비 / 기적의 손길
- 부활: 되살리기 / 가호(P 쓰러짐 방지 확률) / 완전 소생 / 전체 소생 / 천사의 숨결
- 성광: 성광탄 / 정화(상태 이상 해제) / 빛의 장막 / 심판의 빛 / 광휘의 후광

**드루이드** — 줄기: 재생 · 자연 · 야수
- 재생: 새싹(지속 회복) / 재생의 숲 / 뿌리 속박(적 속도↓) / 생명의 나무 / 만개
- 자연: 자연 보호막 / 이슬 / 독 제거 / 태양의 은총 / 대지의 축복
- 야수: 가시 덩굴 / 곰의 가죽(방어↑) / 늑대의 울음 / 독수리의 눈 / 야생의 화신

**성직자** — 줄기: 보호 · 정화 · 응징
- 보호: 수호의 기도(피해 감소) / 성스러운 방패 / 대신 맞기 / 피해 흡수 막 / 불가침
- 정화: 해제 / 축복(상태 이상 저항) / 안식(디버프 방지) / 순백의 종 / 구원의 빛
- 응징: 철퇴 / 응징(받은 피해만큼 반격) / 신벌 / 성스러운 낙인 / 심판의 종

### 특수
**기사** — 줄기: 도발 · 수호 · 검술
- 도발: 도발 / 방패 치기 / 전열 / 불굴의 외침 / 요새
- 수호: 막아서기(아군 대신 맞기) / 방어 태세 / 반격 태세 / 수호의 서약 / 철벽
- 검술: 베기 / 돌격 / 방패 돌진(기절) / 정의의 칼날 / 기사의 일격

**소환사** — 줄기: 정령 · 야수 · 계약
- 정령: 불 정령 / 물 정령 / 바람 정령 / 대지 정령 / 정령왕
- 야수: 늑대 소환 / 곰 소환 / 독수리 소환 / 호박 유령 소환 / 용 소환
- 계약: 소환수 강화(P) / 마력 연결 / 합체 공격 / 송환(소환수 체력 회복) / 계약의 폭주

**기공사** — 줄기: 포탑 · 함정 · 폭탄
- 포탑: 소형 포탑(자동 공격) / 보조 포탑(방어막) / 레이저 포탑 / 포탑 증설 / 요새 포대
- 함정: 덫 설치 / 지뢰 / 전기 그물 / 연쇄 함정 / 대지 폭파
- 폭탄: 수류탄 / 접착탄 / 연막탄 / 시한폭탄(몇 턴 뒤 폭발) / 집중 포화

### 직업 역할 요약 (파티 구성 힌트)
딜러 3 / 서포터 3 / 힐러 3 / 특수 3. 5인 파티에서 **기사 1 + 힐러 1 + 딜러 2~3**이 기본. 같은 직업 중복 허용이라 인원이 적을 때도 구성이 무너지지 않게, 몬스터 체력·피해는 **파티 인원수에 맞춰 보정**해요 (1인 ×0.6 ~ 5인 ×1.4 정도).

## 5. 전투 시스템 🟡
- **시간 게이지(ATB)**: 속도(SPD) 스탯에 따라 게이지가 차고, 가득 차면 그 사람이 행동 입력(제한시간 10초). 입력이 늦으면 자동으로 기본 공격.
  - 협동이라 **전체를 멈출 수 없어요.** 내 차례를 고르는 동안 다른 사람 게이지와 적은 그대로 흘러요.
- 행동: 공격 / 스킬(마력) / 아이템(소모품) / 방어 / 철수(파티 투표, 일부 노드는 불가)
- 속성: 불·얼음·번개·암흑·성광·물리, 적마다 약점/저항. 흑마법사와 연금술사 효과의 핵심.
- 상태 이상: 독, 화상, 출혈, 감속, 기절, 방어↓, 가속 …
- **진행 주체(권한)**: 방장의 기기가 전투를 계산해서 `explore/<방>`에 상태를 올리고, 멤버는 행동 명령만 올려요. 방장이 끊기면 다음 사람이 이어받아요. 부정행위 방지는 가볍게(경제적 피해가 적은 편이라 서버 검증은 생략).
- 연출: 캔버스 전투 화면(기존 이야기 무대와 같은 방식). 아군 아래, 적 위. 스킬마다 이펙트 연출 + 숫자 팝업.
- 전투 길이 목표: 일반 30~60초, 정예 1~2분, 보스 3~5분.
