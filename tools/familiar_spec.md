# 사역마(정령불) 설계서 · 시안

맵에서 플레이어를 따라다니는 정령불 12종. **1인당 1마리**(펫처럼 정해지면 바뀌지 않음). 펫과 달리 **혼자 말을 걸고**(일방적), **친밀도**가 오를수록 말투가 풀리고 **능력**이 열려요.

## 1. 친밀도

| 단계 | 이름 | 누적 점수 |
|---|---|---|
| 0 | 경계 | 0 |
| 1 | 관심 | 100 |
| 2 | 익숙 | 200 |
| 3 | 신뢰 | 300 |
| 4 | 맹약 | 400 |

- 점수는 **선물로만** 올라요. **선물은 하루 한 번**(자정 초기화), 하루 최대 30점.
  - 좋아하는 것: +30
  - 보통인 것: +10
  - 싫어하는 것: −10
- 100점마다 다음 단계. 매일 좋아하는 것을 줘도 단계마다 4일, 최고 단계까지 14일.
- 좋아하는 것은 화면 어디에도 표시하지 않아요. 정령이 평소 대사로 **아주 은근하게** 돌려 말하고(이름을 말하지 않음), 한 번 선물해서 반응을 본 재료만 선물 칸에 ♥/✕로 기억해요.

## 2. 상황 (대사가 나오는 때)

정령이 **약 5시간에 한 번**, 걷고 있을 때 NPC 대화창처럼 갑자기 대화창을 열어 말을 걸어요. 지금 상황과 단계에 맞는 줄 중 **무작위**로 나오고, 플레이어는 다 읽고 닫으면 끝(대답 없음). 선물 반응·단계 오름 대사도 같은 대화창으로 나와요.

| 키 | 언제 |
|---|---|
| greet | 접속했을 때·사역마를 다시 불러냈을 때 |
| idle | 걷는 중 가끔 (2줄씩, 번갈아) |
| still | 한동안 가만히 서 있을 때 |
| gather | 낚시·채집 중 |
| explore | 탐사 출발·전투 중 |
| night | 밤(21시~5시)에 처음 걸 때 |
| weather | 비·눈·안개 같은 날씨 |
| hint | 좋아하는 것을 은근하게 돌려 말하기 (재료 6개마다 한 줄, 이름은 절대 말하지 않음). 평소 대사에 섞여 무작위로 나옴 |
| gift.like / meh / hate | 선물 받았을 때 (좋아함·보통·싫어함) |
| levelup | 단계가 올랐을 때 (1→, 2→, 3→, 4→) |

### 단계별 능력 (균형 맞춤)

모든 능력은 **직업과 상관없이** 똑같이 쓸모 있게(공격 대신 「주 능력치」). 관심~신뢰는 정령마다 다른 **생활 분야**(주력 A, 보조 B), 맹약은 모두 **탐사 능력**. 같은 단계끼리는 크기를 맞췄고, 판을 바꾸는 효과(부활·반사·함정 표시 같은 것)는 넣지 않아요.

| 신뢰 | A +10% (합계) |
| 맹약 | 탐사 능력 하나 (아래 표) + 정령 빛이 더 밝아지고 맹약 대사 |

## 4. 대사 쓰는 규칙

- 말줄임표: 문장 **중간은 점 4개 `....`**, 문장 **끝은 점 7개 `.......`**. `…` 문자는 쓰지 않아요. 모든 문장에 점을 붙이지 않아도 돼요.
- 한 줄은 말풍선 하나: **36자 안팎**, 길어도 50자 이하.
- 단계가 오를수록 말투가 풀려요: 0 경계(차갑거나 낯가림) → 1 관심 → 2 익숙 → 3 신뢰 → 4 맹약(그 정령만의 방식으로 마음을 드러냄. 성격은 유지! 츤데레는 끝까지 츤데레).
- 메타 표현 금지: "친밀도", "단계", "버프", "%", "레벨" 같은 게임 용어를 대사에 쓰지 않아요.
- 플레이어를 부르는 말은 정령마다 고정 (예: Sol 「그대」, Puck 「손님」, Eon 「아가」, Ignis 「너」).
- hint 줄은 재료 이름을 **절대** 쓰지 않아요(이름 일부도 안 됨). 생김새·향·나는 곳·때·느낌으로만 아주 은근하게, 그 정령 말투로 혼잣말처럼. 듣고 바로 정답이 떠오르면 너무 쉬운 거예요.
