# 사역마(정령불) 설계서 · 시안

맵에서 플레이어를 따라다니는 정령불 12종. **1인당 1마리**(펫처럼 정해지면 바뀌지 않음). 펫과 달리 **혼자 말을 걸고**(일방적), **친밀도**가 오를수록 말투가 풀리고 **능력**이 열려요.

## 1. 친밀도

| 단계 | 이름 | 누적 점수 |
|---|---|---|
| 0 | 경계 | 0 |
| 1 | 관심 | 100 |
| 2 | 익숙 | 200 |
| 3 | 신뢰 | 300 |
| 4 | 맹약 | 400 |

- 점수는 **선물로만** 올라요. **선물은 하루 한 번**(자정 초기화), 하루 최대 30점.
  - 좋아하는 것: +30
  - 보통인 것: +10
  - 싫어하는 것: −10
- 100점마다 다음 단계. 매일 좋아하는 것을 줘도 단계마다 4일, 최고 단계까지 14일.
- 좋아하는 것은 화면 어디에도 표시하지 않아요. 정령이 평소 대사로 **아주 은근하게** 돌려 말하고(이름을 말하지 않음), 한 번 선물해서 반응을 본 재료만 선물 칸에 ♥/✕로 기억해요.

## 2. 상황 (대사가 나오는 때)

정령이 **약 5시간에 한 번**, 걷고 있을 때 NPC 대화창처럼 갑자기 대화창을 열어 말을 걸어요. 지금 상황과 단계에 맞는 줄 중 **무작위**로 나오고, 플레이어는 다 읽고 닫으면 끝(대답 없음). 선물 반응·단계 오름 대사도 같은 대화창으로 나와요.

| 키 | 언제 |
|---|---|
| greet | 접속했을 때·사역마를 다시 불러냈을 때 |
| idle | 걷는 중 가끔 (2줄씩, 번갈아) |
| still | 한동안 가만히 서 있을 때 |
| gather | 낚시·채집 중 |
| explore | 탐사 출발·전투 중 |
| night | 밤(21시~5시)에 처음 걸 때 |
| weather | 비·눈·안개 같은 날씨 |
| hint | 좋아하는 것을 은근하게 돌려 말하기 (재료 6개마다 한 줄, 이름은 절대 말하지 않음). 평소 대사에 섞여 무작위로 나옴 |
| gift.like / meh / hate | 선물 받았을 때 (좋아함·보통·싫어함) |
| levelup | 단계가 올랐을 때 (1→, 2→, 3→, 4→) |

## 4. 대사 쓰는 규칙

- 말줄임표: 문장 **중간은 점 4개 `....`**, 문장 **끝은 점 7개 `.......`**. `…` 문자는 쓰지 않아요. 모든 문장에 점을 붙이지 않아도 돼요.
- 한 줄은 말풍선 하나: **36자 안팎**, 길어도 50자 이하.
- 단계가 오를수록 말투가 풀려요: 0 경계(차갑거나 낯가림) → 1 관심 → 2 익숙 → 3 신뢰 → 4 맹약(그 정령만의 방식으로 마음을 드러냄. 성격은 유지! 츤데레는 끝까지 츤데레).
- 메타 표현 금지: "친밀도", "단계", "버프", "%", "레벨" 같은 게임 용어를 대사에 쓰지 않아요.
- 플레이어를 부르는 말은 정령마다 고정 (예: Sol 「그대」, Puck 「손님」, Eon 「아가」, Ignis 「너」).
- hint 줄은 재료 이름을 **절대** 쓰지 않아요(이름 일부도 안 됨). 생김새·향·나는 곳·때·느낌으로만 아주 은근하게, 그 정령 말투로 혼잣말처럼. 듣고 바로 정답이 떠오르면 너무 쉬운 거예요.

## 5. 관리자 배정

- 관리자 「이벤트」 탭의 「사역마 「꺼지지 않는 불씨」」 카드(접었다 펼 수 있어요): 학생마다 드롭다운으로 정령 고르기 → `fam/pick/<uid>` = 정령 번호(0~11)
- 「배정 안 된 N명 고르게 채우기」: 가장 적게 배정된 정령부터 무작위로 나눠 줘요
- 보기 드롭다운: 모든 학생 / 아직 배정 안 됨 / 정령별
- 이미 만난 학생은 바꿀 수 없게 잠겨요 (`players/<uid>/fam = { k }`)
- 이벤트 시작·끝내기 버튼은 학생 쪽 연출을 붙일 때 같이 넣어요

## 6. 만남 이벤트 흐름

1. 사역마가 없는 학생에게 하얀 불씨가 날아와 앞에 멈춰요. 설명 없이 내 머리 위에 「.......!」 말풍선만.
2. 불씨가 **지금 맵에서 가장 가까운 다른 지역으로 가는 길**(학교↔마을·시장↔그림자 골목 같은 지역 이동 길만, 건물 실내 문·탐사 길·잠긴 길은 제외)로 앞장서요. 몇 칸 가서 기다리고, 다가가면 또 앞으로. 입구에 닿으면 문 안으로 스며들어요.
3. 학생이 **지역 이동 길을 타면** 원래 이동 대신 제단 연출 컷(덩굴에 감긴 제단)이 나와요. 이동은 하지 않아요.
4. 제단의 물음 10개를 모두 고르고 → 계약 의식(무지갯빛 → 정령 색) → 이름이 새겨지고 → 첫 대사가 화면 가운데에 한 글자씩.
5. 연출이 끝나면 원래 맵의 그 입구 앞으로 돌아오고, 정령이 곁에 생겨 따라다녀요.

## 7. 이벤트 「정령의 시련」 (각성) · 시안

- 관리자가 이벤트를 열면, 사역마가 있는 학생마다 자기 정령이 어느 날 먼저 말을 걸어 **자기만의 시련**을 부탁해요(성격대로).
- 오른쪽 위에 시련 진행 칸이 떠요. 끝내면 정령이 "따라와"라며 각성 연출 컷으로 데려가요.
- 연출: 바닥에 룬 고리 → 불기둥처럼 빛이 솟고 정령이 떠올라 커짐 → 번쩍임과 함께 **각성한 모습** → 이름이 다시 새겨지고(이름은 그대로) → 각성 대사가 한 글자씩.
- 각성 뒤에는 맵에서도 각성한 모습(크기는 그대로, 모양만 화려하게)으로 따라다녀요. 친구 화면에도 보여요.
- 보상은 모습·대사 위주(능력 수치는 그대로).

**시련은 3막, 최소 1~2주.** 신뢰 단계(300점)부터 시작할 수 있어요. 막마다 정령이 성격대로 말을 걸고, 앞 막을 끝내야 다음 막이 열려요. 3막은 그 정령만의 귀한 재료를 바쳐야 해서 운과 꾸준함이 같이 필요해요.
