# 「광장 픽셀 벽화」 · 시안 1

## 0. 한 줄
광장 담벼락에 커다란 픽셀 캔버스(가로 48 × 세로 32 칸)가 걸려요. 학생마다 하루 20 칸씩만 칠할 수 있어서, 혼자서는 절대 완성 못 하고 반 전체가 함께 그려야 해요. 일주일 뒤 완성본은 학교에 영구 전시돼요.

## 1. 열고 닫기
- 관리자가 「벽화 시작하기」를 누르면 학교 광장 게시판 옆 담벼락에 빈 캔버스와 사다리 · 물감 통이 생겨요.
- 한 주 = 그림 하나. 관리자가 「이번 주 마치기」를 누르거나 7 일이 지나면 액자에 넣어 걸고, 다음 주 캔버스가 새로 걸려요.
- 걸린 완성본은 「벽화 갤러리」(광장 담벼락 옆)에서 계속 볼 수 있어요.

## 2. 시작 연출 (스텔라 · 몽환적인 존댓말)
- 처음 광장에 가면 스텔라가 사다리 위에서 붓을 들고 있어요.
- 「별이 그러는데요.... 이 벽이 심심하대요.」
- 「하루에 스무 칸씩만 칠해 주세요. 한꺼번에 칠하면 별이 놀라서 도망가요.......」
- 「밑그림은 제가 흐릿하게 그려 뒀어요. 그 위에 같은 색을 칠하면, 그림이 하나씩 깨어나요.」
- → 물감 붓 (가방 · 꾸미기 손에 드는 소품).

## 3. 칠하기
- 담벼락을 누르면 벽화 화면이 열려요. 물감 16 색 (게임 옷 색에서 골라요).
- 칸을 누르면 칠해져요. 하루 20 칸 (자정에 다시 20 칸). 방금 칠한 칸은 그날 안에 되돌릴 수 있어요 (칸도 돌려받아요).
- 밑그림: 흐릿하게 이번 주 그림이 깔려 있어요. 켜고 끌 수 있어요. 밑그림과 같은 색으로 칠하면 「딱 맞아요」.
- 남이 칠한 칸 위에도 칠할 수 있어요 (덮어쓰기). 대신 같은 칸을 1 시간 안에 다시 덮을 수는 없어요 (장난 방지).
- 「누가 칠했나」 모드: 칸을 누르면 칠한 학생 이름이 떠요.
- 「크게」: 2.5 배로 키우고 끌어서 옮겨요 (휴대폰에서 작은 칸도 정확히).
- 실시간: 친구가 칠한 칸이 바로 보이고, 아래에 「○○ · (34, 9) 칸을 칠했어요」가 흘러가요.

## 4. 투표 · 다음 주 그림
- 그 주 동안 다음 주 그림 후보 3 개에 한 표씩 (바꿀 수 있어요). 후보 예: 학교 문장 · 눈 내리는 사육장 · 우리 반 얼굴(학생마다 자기 칸에 자기 얼굴).
- 후보 그림은 관리자가 고르거나 새로 넣을 수 있어요 (관리자 화면에서 48 × 32 밑그림 업로드).

## 5. 완성 · 보상
- 밑그림과 맞는 칸이 90 %가 되면 완성 연출: 벽화가 반짝이며 그림 속 부엉이가 한 번 날갯짓해요 (그림마다 작은 움직임 하나).
- 모두에게: 그 주 벽화 미니 액자 (방 가구 · 완성본 그대로 그려요).
- 많이 칠한 학생 3 명: 「벽화가」 이름표 (한 주 동안).
- 타임랩스: 완성본을 누르면 칠한 순서대로 다시 그려지는 영상이 나와요.
- 스텔라 호감도: 하루 첫 칠하기마다 조금.

## 6. 관리자
- 시작 · 이번 주 마치기 · 지금 벽화 미리보기 · 완성률 · 학생별 칠한 칸 수 · 투표 현황.
- 장난 칸 지우기: 관리자는 칸을 눌러 비울 수 있어요 (칠한 학생 이름 확인).

## 7. 저장 (만들 때 참고)
- `mural/ctl = { open, id, week, theme }` · `mural/px/<x_y> = { c 색, u uid, n 이름, t 시각 }` (칸마다 따로 저장 · 동시에 칠해도 칸끼리 안 겹쳐요)
- `mural/vote/<uid> = 후보 번호` · `mural/gallery/<week> = { theme, png(작은 그림), done }`
- `me.mural = { d 날짜, n 오늘 칠한 수, last [최근 칸] }`

## 8. 시안 파일
- `mural_play.html`: 직접 칠해 보는 화면 (밑그림 · 16 색 · 하루 20 칸 · 되돌리기 · 누가 칠했나 · 크게 · 다음 날로 · 타임랩스 · 투표). 친구 이름과 미리 칠한 칸은 예시예요.
