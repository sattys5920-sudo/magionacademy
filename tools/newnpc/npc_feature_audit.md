# 새 친구 셋(도도 · 셀린 · 본) NPC 기능 점검

기존 서브 NPC 11 명(나비 · 배트리 · 캇파 · 아울라 · 맨디 · 스트로 · 세라 · 마들렌 · 스텔라 · 레오 · 오투모)에게 있는 NPC별 내용을 새 친구에게도 맞췄어요.
가림: 만나기 전(`nnMet` 거짓)에는 `npcGet`이 비어서 선물 · 대화 단추가 안 나오고, 목록형 화면은 `nnHide(id)`로 빼요. 「다 모으기」 보상이 걸린 표는 없어요(관리자 화면의 분모만 학생별로 셈).

| 기능 | 고치기 전 (새 친구에게) | 고친 뒤 |
|---|---|---|
| 겨울 뜨개질 · 목도리 선물 (`KN_THX`) | 표에 없어서 선물 칸이 안 보임 | 처음 5 줄 · 또 3 줄씩, NPC 말투로 |
| 좋아하는 목도리 색 (`KN_FAV` · `KN_FAV_SAY`) | 없음 | 도도 파랑(바다) · 셀린 보라(앞치마) · 본 노랑(셔츠 · 눈불) |
| 목도리 두른 그림 (`KN_SP`) | 그림 NPC 목 자리가 없어 목도리가 안 그려짐 | 14 · 15 · 16 번째 줄 앞 · 옆 · 뒤 목 자리 |
| 뜨개 인형 (`KN_DOLLS` · 가구 `kn_doll_*`) | 인형 목록 · 가구 없음 | 인형 3 종 추가(world.js 가구 맨 뒤에 덧붙임 · 기존 번호 그대로), 못 만난 학생 목록에선 빠짐 |
| 뜨개 키링 (`KR_THX` · `KR_ANCH`) | 다는 자리가 없어 키링 칸이 안 보임 | 한마디 + 다는 자리(앞 · 뒤 · 옆) |
| 꽃말 꽃다발 (`BQ_NPCS` · `BQ_RECALL`) | 꽃다발 칸 안 보임 · 회상 없음 | 좋아하는 꽃 / 싫어하는 꽃 / 고백 · 장난 · 기본 대사, 회상 3 단계 (고백 꽃말은 우정으로 돌려 받음) |
| 마음 풍선 (`BLN_STORY`) | 「풍선 주기」 없음 | 이야기 3 편 (앞부분 · 다시 · 맞음 · 비슷한 마음 둘 · 틀림 · 기다림 · 끝난 뒤), 장소: 시계탑 꼭대기 · 그림자 골목 수선집 · 묘지 |
| 배트리의 쏟아진 편지 (`LT_LETTERS` · `LT_NPC` · `LT_PX` · `LT_THANKS`) | 편지 없음 | 편지 3 통 × 답장 3 개 + 답장 받은 뒤 대사, 편지지 · 글꼴 · 장식 그림, 고마움 한마디 |
| 편지 자동 배정 (`ltAuto`) | 11 명 고정 | 앞 33 칸은 그대로(기존 배정 안 바뀜) · 그 뒤 칸만 이벤트 시작 전에 그 친구를 만난 학생에게 새 친구 편지. 못 만난 학생에게 배정되면 배트리가 대신 씀. 관리자 고르기도 만난 학생에게만 |
| 마들렌의 쿠키 상자 (`NPCS` · `DRAWN` · `REACT`) | 쿠키 상자 칸 안 보임 | 좋아하는 맛 · 모양 · 힌트 · 반응 4 단계 · 받는 연출(도도 「낙찰!」 도장 · 셀린 「계약 성립」 도장 · 본 별 터뜨리기), 단골 수첩은 만난 친구만 |
| 아울라의 책갈피 (`NPCB` · 무늬 · `FX`) | 없음 | NPC 책갈피 3 종(무늬 · 재료 · 효과), 못 만나면 목록 · 개수에서 빠짐 |
| 엔딩 (`playEnding`) | 둘러서는 목록에 없음 | 바깥 고리에 추가 (만난 학생 화면에서만) |
| 누비 소문 (`NB_RUMOR`) | 없음 | 소문 한마디씩 |
| 대화 · 선물 · 회상 · 관계 패널 | profile.json으로 이미 됨 | 그대로 |
| 관리자 화면 | 풍선 「11 명」 문구 · 뜨개 「10 종」 문구 | 개수를 표에서 셈 · 풍선 완성 분모는 학생이 만난 친구만 |
| 시간 캡슐 · 창밖 정원 · 요정 시장 · 무슈 블랑 | NPC별 표 없음 (스텔라 · 맨디 · 동물 손님 고정 · 이름만 씀) | 해당 없음 |
| 장난 마법(`PRANK_STEPS`) | 마법마다 정해진 NPC 조건 (NPC별 표 아님) | 해당 없음 · 「하트 3 개 친구 셋」은 새 친구도 셈 |
| 메인 의뢰 회상(`npc_lines.json`) | 일부 NPC만 있음 (오투모도 없음) · 새 친구는 의뢰 뒤에 온 손님 | 넣지 않음 |
