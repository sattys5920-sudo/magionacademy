# NPC 호감도 스토리 전면 작성 작업 지시서

너는 이 게임의 시나리오 작가이자 개발자야. 마을 NPC 10 명(동물 NPC 6 명 + 꾸미는 사람 NPC 4 명)의 호감도 스토리를 처음부터 끝까지 써서 게임 데이터로 넣고, 그걸 돌릴 대화·호감도 시스템까지 맞춰 줘.
분량이 크니까 아래 순서대로 NPC 1 명씩 끝내고, 끝날 때마다 검증 스크립트를 돌려서 통과한 다음에 다음 NPC로 넘어가.

---

## 0. 먼저 할 일 (코드 파악)

1. 지금 프로젝트에 있는 아래 항목을 찾아서 구조를 요약해 줘. 새로 만들기 전에 반드시 기존 구조를 확인해.
   - NPC 데이터(이름, 위치, 선물 선호, 대사)
   - 대화창·초상화·선택지 UI
   - 호감도(하트) 값과 저장 방식
   - 장소(맵) 목록과 장면 전환 기능
   - 관리자 페이지에서 사람 NPC를 수정하는 기능
2. 기존 구조가 있으면 그 형식에 맞춰 확장해. 없는 기능만 아래 설계대로 새로 만들어.
3. 기존 NPC 설정(성격, 이야기, 하트 이벤트 제목)은 이 문서 내용으로 바꿔도 돼. 이 문서가 우선이야.

## 1. 게임 배경 (모든 대사의 전제)

- 무대: 마녀 학교가 있는 작은 마을. 주인공 `{player}`는 이번 학기에 입학한 신입 마녀 학생이야.
- 주요 장소(이벤트 이동 연출에 쓰는 장소 ID 예시. 실제 맵 ID가 있으면 그걸 써.)
  - `lantern_market` 등불 시장 / `fish_stall` 생선 가게 / `market_alley` 시장 뒷골목 / `market_roof` 시장 지붕
  - `owl_post` 부엉이 우체국 / `optician` 시장 안경점
  - `ghost_lake_pier` 유령 호수 잔교 / `ghost_lake_cave` 호수 동굴
  - `main_hall` 본관 / `potion_class` 물약 교실 / `library_stacks` 도서관 서고 / `infirmary` 양호실 / `clock_tower` 시계탑
  - `poison_greenhouse` 독초 온실 / `pumpkin_field` 호박밭 / `old_windmill` 낡은 풍차
  - `candy_class` 과자 교실 / `witch_hut` 마녀의 오두막 / `hill_ruin` 언덕 위 무너진 오두막
  - `menagerie` 사육장 / `swamp` 늪지 / `player_room` 내 방 / `village_square` 마을 광장 / `station` 마차 정류장
- 시간대: 아침, 낮, 저녁, 밤. 날씨: 맑음, 비, 안개, 눈. 축제: 호박달 축제(가을 보름).
- 메인 스토리 떡밥: "별자리가 이상하다"는 징조가 마을 전체에 깔려 있어. 스텔라 이야기에서 가장 많이 다루고, 다른 NPC는 지나가는 말로 1~2 번만 언급해.

## 2. 호감도 시스템 설계

### 2-1. 수치
- 하트 0~10. 하트 1 칸 = 호감도 100 점.
- 오르는 방법
  - 그날 첫 대화 +10
  - 선물: 좋아함 +40, 보통 +15, 싫어함 −30 (같은 NPC에게 하루 1 번)
  - 하트 이벤트 안의 선택지: +30 / +15 / 0 / −15 / −30
- 떨어지는 방법
  - 싫어하는 선물, 하트 이벤트에서 상처 주는 선택
  - 7 일 동안 한 번도 말을 걸지 않으면 하루에 −5 (현재 하트 칸의 0 점 아래로는 안 떨어짐)
- 하트 이벤트를 본 뒤에는 그 하트 칸 밑으로 내려가도 이벤트를 다시 보지 않아. 대신 평소 대사 말투는 현재 하트 기준으로 돌아가.

### 2-2. 하트 이벤트 조건 (페르소나식 진행)
- 하트 이벤트는 ♥1부터 ♥10까지 NPC마다 10 개.
- 열리는 조건 = 하트 수치 + 장소 + 시간대 (+ 일부는 날씨, 요일, 메인 스토리 진행, 다른 NPC 이벤트 완료)
  - 예: 나비 ♥3은 "하트 3 이상 + 비 오는 날 + 등불 시장 + 저녁".
- 조건이 맞으면 해당 장소에 NPC 머리 위로 ❗ 아이콘을 띄워.
- 한 날에 하트 이벤트는 NPC 1 명당 1 개만.

### 2-3. 선택지 규칙
- 이벤트마다 선택지 지점 3~5 개. 지점마다 보기 2~4 개.
- 보기마다 호감도 변화가 있어. 이벤트 하나 안에 상승(+)·유지(0)·하락(−) 보기가 모두 있어야 해.
- 정답이 뻔하지 않게 써. "다정하게 다가가기"가 오히려 하락인 장면도 있어야 해. (예: 나비에게 허락 없이 손을 뻗으면 하락)
- 중요한 선택은 플래그를 남기고, 이후 이벤트 대사가 그 플래그에 따라 몇 줄씩 달라지게 해. NPC마다 이런 분기 플래그를 최소 3 개 만들어.
- 이벤트 안에서 받은 호감도 합이 −30 이하면 "이벤트는 끝났지만 서먹한" 결말 대사(5~10 줄)로 끝나고, 다음 이벤트 첫머리에 그걸 언급하게 해.

### 2-4. 말투 단계
- NPC마다 말투 단계를 4 개 둬: A(하트 0~2), B(3~5), C(6~8), D(9~10).
- 단계마다 호칭, 존댓말/반말, 문장 길이, 말버릇, 먼저 말을 거는지가 달라져. 캐릭터별 표는 5 장에 있어.
- 평소 대사(하트 이벤트가 아닌 일상 대화)는 단계마다 최소 12 줄, 날씨·시간대별 대사 6 줄, 선물 반응 대사(좋아함/보통/싫어함 각 3 줄)를 따로 만들어.
- 하트가 오를수록 평소 대사에도 그동안의 이야기를 떠올리는 말이 섞이게 해.

## 3. 대사 스크립트 데이터 형식

### 3-1. 파일 구조 (기존 구조가 있으면 거기에 맞춰)
```
data/npc/<npc_id>/profile.json        # 이름, 위치, 선물, 말투 단계, 일상 대사
data/npc/<npc_id>/events/heart_01.json
...
data/npc/<npc_id>/events/heart_10.json
```

### 3-2. 이벤트 파일 형식
```json
{
  "id": "nabi_heart_03",
  "npc": "nabi",
  "heart": 3,
  "title": "비 오는 날의 상자",
  "conditions": { "minHeart": 3, "location": "lantern_market", "time": ["evening"], "weather": ["rain"] },
  "rewards": { "items": [], "flags": ["nabi_umbrella"] },
  "script": [
    { "cmd": "fade_in" },
    { "cmd": "line", "who": "nabi", "face": "annoyed", "text": "……뭘 봐. 비 피하는 고양이 처음 봐?" },
    { "cmd": "line", "who": "player", "text": "(차양 끝에서 빗물이 줄줄 떨어지고 있다.)" },
    { "cmd": "choice", "id": "c1", "options": [
      { "text": "우산 같이 쓸래?", "affinity": 15, "next": "c1_umbrella" },
      { "text": "그냥 옆에 조용히 선다.", "affinity": 30, "next": "c1_quiet", "flag": "nabi_respect_space" },
      { "text": "번쩍 안아 올린다.", "affinity": -30, "next": "c1_grab" }
    ]},
    { "label": "c1_quiet" },
    { "cmd": "line", "who": "nabi", "face": "neutral", "text": "……흥. 거기 서 있으면 너도 젖어." },
    { "cmd": "move", "to": "market_alley", "transition": "fade" },
    { "cmd": "walk", "who": "nabi", "to": "box_spot" },
    { "cmd": "emote", "who": "nabi", "icon": "sweat" },
    { "cmd": "sfx", "id": "rain_heavy" },
    { "cmd": "if_flag", "flag": "nabi_fish_promise", "then": "fish_callback", "else": "no_callback" },
    { "cmd": "fade_out" }
  ]
}
```

### 3-3. 지원해야 할 명령 (엔진에 없으면 최소 구현을 추가해)
| 명령 | 뜻 |
|---|---|
| `line` | 대사 한 줄. `who`, `face`(표정), `text` |
| `narration` | 지문(괄호 대사 대신 쓸 수 있음) |
| `choice` | 선택지. 보기마다 `affinity`, `next`, `flag`(선택) |
| `label` / `goto` | 분기 이동 |
| `if_flag` / `if_heart` | 플래그나 하트 수치로 분기 |
| `move` | 다른 장소로 장면 이동(`transition`: fade, cut) |
| `walk` | 캐릭터를 지점까지 걸어가게 함 |
| `follow` | NPC가 앞장서고 주인공이 따라가는 이동 연출 |
| `emote` | 머리 위 감정 아이콘(heart, sweat, angry, music, question, exclaim, zzz, tear) |
| `camera` | 카메라 이동·흔들림 |
| `sfx` / `bgm` | 효과음, 배경 음악 전환 |
| `wait` | 몇 초 멈춤(연출용 침묵) |
| `give_item` / `take_item` | 아이템 주고받기 |
| `set_flag` | 플래그 저장 |
| `affinity` | 선택지 밖에서 호감도 직접 변경 |
| `fade_in` / `fade_out` | 화면 전환 |

### 3-4. 줄 수 세는 법
- `line`, `narration` 하나 = 1 줄. 선택지 보기 문구는 줄 수에 넣지 않아.
- 분기가 있으면 "플레이어가 실제로 보게 되는 한 경로"를 기준으로 세.

## 4. 분량과 문장 규칙

### 4-1. 분량
- 하트 이벤트 1 개 = 한 경로 기준 **90~120 줄**.
- ♥5, ♥8, ♥10은 이야기의 큰 고비라 **110~140 줄**.
- 모든 이벤트에 장면 이동(`move` 또는 `follow`)을 최소 1 번 넣어. ♥5 이후 이벤트는 2 번 이상 이동하는 것도 좋아.
  예: 이야기하다가 "따라와." 하고 다른 장소로 가서 뭔가를 보여 주기.
- 하트가 오를수록 NPC가 하는 말이 길어지고, 속마음이 더 드러나게 해. 앞쪽 이벤트에서 NPC는 대사를 짧게 끊고 주인공이 더 많이 말해. 뒤로 갈수록 그 비율이 뒤집혀.

### 4-2. 국어 규칙 (반드시 지켜)
- 맞춤법과 띄어쓰기는 **표준국어대사전과 한글 맞춤법 규정**을 따라.
- **숫자 뒤에 단위 명사가 오면 반드시 한 칸 띄어 써.**
  - 맞음: `3 일`, `6 번`, `10 마리`, `30 년째`, `2 시`, `5 분`, `100 골드`, `4 명`, `1 개`, `3 번째`, `7 살`
  - 틀림: `3일`, `6번`, `10마리`, `30년째`
  - 숫자를 한글로 쓸 때는 원래 규정대로: `세 번`, `한 마리`, `열 살`
- 자주 틀리는 것 점검 목록
  - 되/돼 (됐어, 돼요, 되어), 안/않 (안 해, 하지 않아)
  - 며칠(몇 일 ×), 금세(금새 ×), 웬일(왠일 ×), 왠지(웬지 ×), 어떡해(어떻해 ×), 할게(할께 ×), 설렘(설레임 ×), 바람(바램 ×), 일부러(일부로 ×), 오랜만(오랫만 ×), 굳이(구지 ×), 역할(역활 ×), 희한하다(희안하다 ×)
  - 의존 명사 띄어쓰기: `할 수 있어`, `먹을 것`, `그럴 줄 알았어`, `간 지 3 년`, `올 때`, `먹는 데 1 시간`
  - 보조 용언: `먹어 보다`, `가 버렸어`, `해 줄게` (붙여 쓰기도 허용되지만 이 프로젝트에서는 **띄어 쓰는 쪽으로 통일**)
  - `-ㄹ게`, `-ㄹ걸`은 붙여 쓰고, `-ㄹ 거야`는 띄어 써.
- 문장 부호
  - 말줄임표는 점으로 쓰고 말 중간은 점 4 개(`....`), 말 끝은 점 7 개(`.......`)로 통일. `…`, `……`, 점 3 개는 쓰지 마. (`tools/dots.py`가 옛 표기를 한 번에 바꿔 줘요)
  - 책 제목은 『 』, 노래·편지·작품 이름은 「 」.
  - 물음표·느낌표를 겹쳐 쓰지 마(`?!`, `!!` 금지). 강조가 필요하면 연출(`emote`, `camera` 흔들림)로 처리해.
- 캐릭터 말버릇은 써도 되지만 맞춤법을 깨는 표기는 쓰지 마. (예: 고양이라고 해서 문장마다 "냥"을 붙이지 않아.)
- 의성어·의태어는 표준어로 써. (`살금살금`, `펄럭`, `철퍽`)
- 이름이 바뀔 수 있는 사람 NPC는 대사에 이름을 직접 쓰지 말고 `{npc.name}`, `{npc.husband}`처럼 변수로 써. 외모가 바뀔 수 있으니 성별을 단정하는 표현(그녀, 아저씨 등)은 사람 NPC 대사에 쓰지 마.

### 4-3. 글쓰기 원칙
- 감동은 설명이 아니라 장면으로 만들어. "외로웠어." 대신 혼자 쓰던 물건, 습관, 침묵, 날씨로 보여 줘.
- 앞 이벤트에 나온 작은 물건이나 말 한마디를 뒤 이벤트에서 다시 꺼내서(복선 회수) 울컥하게 만들어.
- 무거운 장면 사이사이에 그 캐릭터다운 웃음 포인트를 꼭 넣어. 한 이벤트가 끝까지 울기만 하면 안 돼.
- 교훈을 NPC가 연설처럼 말하게 하지 마. 깨달음은 짧은 한마디나 행동으로 끝내.
- 주인공 선택지 문구는 세 가지 결을 섞어: 다정한 말, 장난스러운 말, 무심하거나 서툰 말.
- NPC끼리 서로 언급하는 교차 장면을 넣어. 캐릭터별 설계에 표시한 교차 지점은 꼭 지켜.

## 5. 캐릭터별 이야기 설계

아래는 뼈대야. 각 이벤트의 장면, 대사, 선택지, 분기는 이 뼈대를 지키면서 네가 풍부하게 채워.
"핵심 장면"과 "꼭 넣을 대사 방향"은 반드시 들어가야 하고, 나머지는 자유롭게 늘려도 돼.

---

### 5-1. 나비 — 매점 고양이 · 등불 시장 생선 가게 옆

**성격:** 새침하고 날이 서 있어. 사람을 믿지 않고 "주인 따위 필요 없어"라고 입버릇처럼 말해. 그래도 생선 앞에서는 체면을 잃어.
**좋아함:** 호박 붕어, 유령 피라미 튀김, 개박하 / **싫어함:** 물풀 뭉치
**상처:** 세 번 버림받았다고 믿고 있어.
1. 첫 주인인 늙은 마녀 오르솔라. 어느 밤 말없이 사라졌어.
2. 나비를 데려간 가족. 이사 가면서 비 오는 날 나비를 상자에 담아 시장에 두고 갔어.
3. 생선 가게 견습생. 매일 밥을 주다가 어느 날부터 오지 않았어.
**주제:** 버림받을까 봐 먼저 밀어내던 고양이가, 다시 누군가를 고를 용기를 내는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "야", "인간" | 짧은 반말, 비꼼, 먼저 말 걸지 않음, "흥." |
| B | "너" | 반말, 조금 길어짐, 투덜대며 챙겨 줌 |
| C | "{player}" | 반말, 가끔 말끝이 흐려지고 속마음이 새어 나옴 |
| D | "{player}"(가끔 "내 사람") | 반말, 솔직하지만 여전히 새침, 먼저 찾아와 기다림 |

**하트 이벤트**
- ♥1 「생선 도둑」 (생선 가게, 낮): 나비가 생선을 훔치다 주인공과 눈이 마주쳐. 쫓기/모른 척/값 대신 내 주기 선택. 값을 내 주면 "동정하지 마."라며 오히려 하락. 모른 척하면 상승.
- ♥2 「생선 이야기」 (생선 가게 옆, 저녁): 호박 붕어 맛있게 굽는 법을 늘어놓으며 처음으로 길게 말해. 혼자 사는 게 편하다고 강조하는데, 생선 가게 견습생 이야기가 나오자 말을 끊어. 플래그 `nabi_fish_promise`(다음에 호박 붕어를 가져오겠다고 약속).
- ♥3 「비 오는 날의 상자」 (등불 시장 → 시장 뒷골목, 저녁, 비): 비를 피하던 나비가 골목의 젖은 상자를 보고 털을 세워. 두 번째 주인 이야기의 첫 조각을 흘려. 허락 없이 안아 올리면 크게 하락.
- ♥4 「앞발」 (시장 지붕, 밤): 아이들에게 쫓기다 앞발을 다친 나비. "도와 달라고 한 적 없어." 붕대를 감아 주는 장면. 선택에 따라 처음으로 주인공 손등에 머리를 한 번 비비거나, 다시 도망쳐.
- ♥5 「오래된 방울」 (생선 가게 → 언덕 위 무너진 오두막, 저녁) ★큰 고비: 목에 숨겨 두던 녹슨 방울을 보여 주고 "따라와."라며 언덕으로 앞장서. 오르솔라와 살던 오두막 터. 난롯가, 마른 약초, 고양이 발자국이 찍힌 문지방. "그 사람은 마지막 날까지 아무 말도 없었어." 방울을 흔들어도 소리가 안 나는 이유가 궁금해지게 복선을 깔아(안에 뭔가 끼어 있음).
- ♥6 「마차 정류장」 (마차 정류장, 비): 두 번째 가족에게 버려진 곳. 그 가족이 남긴 낡은 털실 공. 분노와 체념. "사람은 다 떠나. 너도 졸업하면 떠날 거잖아." 주인공의 대답이 이후 플래그 `nabi_promise_stay` 또는 `nabi_honest_answer`로 갈려.
- ♥7 「시험」 (조건: ♥6 이후 나비가 3 일 동안 사라짐): 일부러 숨어서 주인공이 찾으러 오는지 시험해. 시장 사람들에게 물어 단서를 모아 시장 지붕 위 등불 사이에서 찾아내는 이동 연출. 3 일 안에 못 찾으면 호감도 −50과 서운한 결말. 찾으면 "……늦었어. 그래도 왔네."
- ♥8 「쪽지」 (언덕 위 무너진 오두막, 밤) ★큰 고비: 방울 속에 접힌 쪽지가 끼어 있었어. 함께 펼쳐 읽어. 오르솔라는 병이 깊어 떠날 때를 알았고, 나비가 기다리다 지치지 않게 일부러 말하지 않았던 것. 쪽지 내용 방향: "나비야, 나를 기다리지 마라. 너를 좋아해 줄 사람을, 이번엔 네가 골라라." 나비는 우는 대신 "비가 와서 그래."라고 해. 하늘은 맑아.
- ♥9 「마지막 기다림」 (언덕 위 무너진 오두막 → 생선 가게, 새벽): 나비가 오두막 문지방에 방울을 내려놓고 작별 인사를 해. "이제 안 기다려도 되지?" 돌아오는 길에 처음으로 주인공 발걸음에 맞춰 나란히 걸어. 견습생이 사실 다른 마을로 일을 배우러 떠나며 생선 가게 주인에게 나비 밥을 부탁했다는 걸 알게 되는 작은 반전(교차: 생선 가게 주인).
- ♥10 「내가 고른 사람」 (내 방, 밤) ★최종: 나비가 주인공 방 창문으로 들어와 기다리고 있어. "착각하지 마. 주인은 내가 정하는 거야. ……너로 정했어." 보상: 내 방 고양이 가구 + 낚시 미끼 효과. 이후 평소 대사에 오르솔라와 방울 이야기를 담담하게 꺼내는 대사 추가.

### 5-2. 배트리 — 우체부 박쥐 · 부엉이 우체국 앞

**성격:** 수다쟁이에 길치. 편지를 자꾸 엉뚱한 데 배달해. 사실 말이 많은 건 불안을 덮으려는 거야.
**좋아함:** 산딸기, 블루베리, 꿀 군밤 꼬치 / **싫어함:** 고추처럼 매운 것
**상처:** 우체국장 그레이(늙은 부엉이)에게 매일 혼나고, 선배 우체부 까치 '깍순'에게 놀림받아. "박쥐인데 밤눈이 어둡다"는 걸 들킬까 봐 안경을 못 써.
**주제:** 스스로를 실수투성이라고 믿던 박쥐가, 자기 실수와 수다가 사실 사람들을 이어 주고 있었다는 걸 알게 되는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "손님", "학생님" | 과하게 공손한 존댓말, 말이 빠르고 사과가 잦음("죄송해요, 죄송해요!") |
| B | "{player} 씨" | 존댓말, 수다가 자연스러워지고 동네 소식을 줄줄 이야기 |
| C | "{player}" | 반말 섞인 존댓말, 걱정이나 고민을 털어놓음 |
| D | "{player}" | 편한 반말, 사과보다 "고마워"가 많아짐, 자기 자랑도 가끔 함 |

**하트 이벤트**
- ♥1 「쿵」 (부엉이 우체국 앞, 아침): 편지 가방을 멘 채 주인공과 정면으로 부딪혀. 편지가 흩어지고 줍는 동안 쉴 새 없이 사과하고 떠들어.
- ♥2 「잘못 간 편지」 (우체국 → 호박밭, 낮): 주인공 집에 온 편지가 사실 호박밭 짚신 앞으로 온 것. 같이 다시 배달하러 가(교차: 짚신이 편지를 처음 받아 봄).
- ♥3 「국장님의 호통」 (우체국 안, 낮): 사람들 앞에서 크게 혼나는 배트리. 깍순이 비웃어. 주인공 선택: 대신 변명해 주기(국장 앞에서 오히려 더 난처해져 하락), 모른 척하고 나중에 찾아가기(상승), 같이 웃기(크게 하락).
- ♥4 「밤 배달 연습」 (마을 광장 → 시계탑 아래, 밤): 몰래 밤에 배달 길을 외우는 배트리를 만나. 같이 길을 걸으며 동네 사람들 한 명 한 명 이야기를 다 기억하고 있다는 걸 알게 돼. 길은 못 외워도 사람은 외우는 박쥐.
- ♥5 「안경 고백」 (우체국 앞 → 시장 안경점, 저녁) ★큰 고비: 사실 밤눈이 어둡다고 고백해. 안경점 앞까지 같이 가지만 유리창에 비친 자기 모습을 보고 도망쳐. "박쥐가 안경을 쓰면 다들 웃을 거예요."
- ♥6 「사표」 (우체국 뒤편, 비): 큰 실수로 중요한 편지를 잃어버리고 사표를 써 둔 배트리. 주인공과 함께 잃어버린 편지를 찾으러 마을을 도는 이동 연출(우체통, 광장 분수, 나무 위). 찾았을 때 사표를 찢을지 말지는 선택에 따라 달라짐.
- ♥7 「길 잃은 우체부님께」 (우체국, 아침): 예전에 잘못 배달한 편지 덕분에 20 년 동안 연락이 끊겼던 할머니와 손자가 다시 만났다는 감사 편지가 와. 받는 사람은 "길 잃은 우체부님께". 배트리가 편지를 들고 한참 말이 없어.
- ♥8 「반딧불이 배달」 (우체국 → 늪지 → 양호실, 폭풍우 밤) ★큰 고비: 급한 약 편지를 양호실로 보내야 하는데 폭풍우로 길이 안 보여. 주인공이 반딧불이를 모아 길을 밝혀 주고 함께 날아가. 무사히 도착해 세라 선생님이 고마워해(교차: 세라).
- ♥9 「처음 보는 별」 (안경점 → 시계탑 꼭대기, 밤): 드디어 안경을 맞춰. 시계탑 꼭대기에서 처음으로 별을 선명하게 보고 수다쟁이가 말을 잃어. 그리고 다시 쉴 새 없이 별 이야기를 해.
- ♥10 「특급 우체부」 (우체국, 아침) ★최종: 안경을 쓰고 출근한 배트리. 그레이 국장이 감사 편지 묶음을 보여 주며 "길은 몰라도 사람은 아는 우체부"라고 인정해. 깍순도 머쓱하게 사과해. 배트리가 주인공에게 "{player} 편지는 평생 공짜로 배달할게!" 보상: 친구에게 선물 보내기 무료.

### 5-3. 캇파 — 낚시꾼 갓파 · 유령 호수 잔교

**성격:** 느긋한 낚시 고수. 머리 접시의 물이 마르면 힘이 쭉 빠져 말도 느려져. 농담을 툭툭 던지는 할아버지 같은 갓파.
**좋아함:** 완두콩, 달빛 이슬, 무지개 송어 초밥 / **싫어함:** 깡통
**이야기:** 「호수의 주인」이라는 전설의 물고기를 30 년째 쫓고 있어. 이 전설은 어린 캇파에게 낚시를 가르쳐 준 사부(돌아가신 늙은 갓파)가 들려준 거야.
**반전:** 사부는 어린 캇파가 매일 호수에 나오게 하려고 이야기를 부풀렸어. 하지만 호수의 주인은 실제로 있었고, 사부와 같은 나이의 늙은 물고기야. 30 년을 매일 호수에 나온 캇파는 어느새 호수의 모든 물길을 아는 사람, 사부가 말한 진짜 "호수의 주인"이 되어 있었어.
**주제:** 꿈은 잡는 것이 아니라 매일 그 곁에서 사는 것. 끈기가 사람을 만든다.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "젊은이" | 느긋한 하게체("~하게", "~하네"), 말수가 적고 농담으로 넘김 |
| B | "자네" | 하게체, 낚시 이야기를 길게 함 |
| C | "{player} 자네" | 사부와 지난 30 년 이야기를 꺼냄, 가끔 약한 소리 |
| D | "{player}", "내 낚시 친구" | 하게체와 반말이 섞인 편한 말투, 웃음이 많음 |

**하트 이벤트**
- ♥1 「입질」 (유령 호수 잔교, 새벽): 말없이 낚싯대를 드리운 캇파 옆에 앉게 돼. 말을 많이 걸면 하락, 조용히 같이 기다리면 상승.
- ♥2 「낚시 요령」 (잔교, 아침): 미끼 끼우는 법, 바람 읽는 법. 처음으로 호수의 주인 이야기를 꺼내.
- ♥3 「깡통」 (호숫가, 낮): 호수에 버려진 깡통을 줍는 캇파. "사부님이 그러셨지. 호수는 받은 만큼 돌려준다고." 같이 청소하는 이동 연출.
- ♥4 「마른 접시」 (잔교, 맑고 더운 날): 접시 물이 말라 쓰러진 캇파. 주인공이 호수 물이나 달빛 이슬로 채워 줘(달빛 이슬이면 더 상승).
- ♥5 「사부의 낚싯대」 (잔교 → 호숫가 오두막, 저녁) ★큰 고비: 오두막에 걸린 낡은 대나무 낚싯대. 사부 이야기와 "30 년 동안 하루도 빠짐없이"의 무게. 접시 물을 채워 주는 의식처럼, 이제 캇파가 주인공에게 낚싯줄 묶는 법을 가르쳐.
- ♥6 「포기」 (잔교, 비): 캇파가 낚싯대를 내려놓으며 "이제 그만둘까 하네. 없는 걸 쫓는 늙은이 같아서." 주인공의 대답이 플래그 `kappa_keep_dream` / `kappa_rest_ok`로 갈려. 둘 다 나쁜 답은 아니지만 이후 대사가 달라져.
- ♥7 「사부의 일지」 (호숫가 오두막, 밤): 오두막 마루 밑에서 사부의 낚시 일지를 찾아. 마지막 장: "녀석이 매일 나오기만 하면 된다. 주인은 언젠가 녀석을 알아볼 거다."
- ♥8 「주인을 본 밤」 (잔교 → 유령 호수 동굴, 보름 밤) ★큰 고비: 30 년 전 단 한 번 주인을 봤던 밤 이야기. 이야기를 듣다가 실제로 물결이 일고 둘이 배를 타고 동굴까지 쫓아가. 은빛 비늘이 아주 잠깐 보이고 사라져.
- ♥9 「같은 나이」 (유령 호수 동굴, 새벽): 드디어 마주친 호수의 주인. 비늘이 하얗게 센 늙은 물고기가 캇파를 피하지 않고 가만히 바라봐. 캇파는 이 물고기도 사부와 같은 나이일 거라는 걸 깨달아.
- ♥10 「놓아주는 손」 (잔교, 아침) ★최종: 마침내 낚싯줄에 걸린 주인. 캇파는 한참 들여다보다 놓아줘. "잡으려고 30 년을 왔는데, 같이 늙으려고 30 년을 왔더구먼." 사부의 일지 마지막 장에 캇파가 한 줄을 덧붙여. 보상: 낚싯대 보너스 + 호수의 주인이 나오는 날을 알려 주는 힌트.

### 5-4. 아울라 — 사서 부엉이 · 본관 물약 교실

**성격:** 깐깐하고 잔소리가 많지만 학생을 아껴. 밤엔 또랑또랑, 낮엔 꾸벅꾸벅 졸아.
**좋아함:** 부엉이 깃털, 세잎클로버 차, 별가루 쿠키 / **싫어함:** 독사과 캔디
**상처:** 아끼던 제자 리나. 리나의 고향에 돌림병이 돌자, 리나는 금서 『사라진 물약 100선』의 해독 물약을 만들겠다며 학교를 떠나려 했어. 아울라는 위험하다고 막으며 "나가면 다시는 돌아오지 마라."라고 했고, 리나는 책의 몇 장을 찢어 들고 떠났어. 그 뒤로 아울라는 학생에게 정을 주지 않으려고 해.
**진실:** 리나는 고향을 살렸고 지금은 떠돌이 치유사로 살아. 해마다 이름 없는 봉투에 찢어 간 책장을 한 장씩 돌려보냈는데, 아울라는 열어 보지도 못하고 서고 깊숙이 넣어 두었어.
**주제:** 떠나보내는 것도 사랑이라는 걸 받아들이는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "학생" | 딱딱한 존댓말, 짧은 지적, 감정 표현 없음 |
| B | "{player} 학생" | 존댓말, 잔소리가 길어지고 칭찬을 숨겨서 함 |
| C | "{player} 학생"(가끔 "그 아이" 이야기) | 존댓말이 부드러워짐, 과거를 조금씩 꺼냄 |
| D | "{player}" | 다정한 반말, 학생을 놓아줄 줄 아는 말 |

**하트 이벤트**
- ♥1 「졸고 있는 선생님」 (물약 교실, 낮): 수업 중 졸던 아울라를 깨울지, 그냥 둘지, 몰래 담요를 덮어 줄지.
- ♥2 「공부 잔소리」 (물약 교실, 저녁): 숙제를 붙잡고 잔소리하지만 주인공 필기 습관이 누군가와 닮았다고 중얼거려(리나 복선).
- ♥3 「밤의 도서관」 (도서관 서고, 밤): 밤에만 문을 여는 서고. 또랑또랑해진 아울라가 책 이야기를 신나게 해. 그러다 비어 있는 책장 한 칸 앞에서 말을 멈춰.
- ♥4 「실패한 물약」 (물약 교실, 낮): 주인공 물약이 폭발해. 크게 화를 내다가 다친 데 없냐며 손을 떨어. 과하게 걱정하는 이유를 숨겨.
- ♥5 「금서」 (물약 교실 → 도서관 서고, 밤) ★큰 고비: 『사라진 물약 100선』 이야기. 서고 가장 깊은 곳 잠긴 칸으로 데려가서 몇 장이 찢겨 나간 책을 보여 줘. "가르친 걸 후회한 학생이 딱 한 명 있어요."
- ♥6 「리나의 자리」 (물약 교실 맨 뒷자리, 비): 리나가 앉던 자리와 책상에 새긴 작은 부엉이 그림. 그날 했던 말을 처음으로 털어놓아.
- ♥7 「도망」 (본관 복도, 낮): 주인공이 다른 선생님에게 칭찬받자 아울라가 일부러 차갑게 대해. 다시 정이 들까 봐 무서운 거야. 따지기/기다리기/쪽지 남기기 선택.
- ♥8 「찢어진 페이지」 (도서관 서고 깊은 곳 → 아울라 연구실, 밤) ★큰 고비: 서고 구석에서 뜯지 않은 봉투 수십 개를 찾아. 봉투마다 책장 한 장과 짧은 소식. 함께 하나씩 열어. 마지막 봉투: "선생님 덕분에 돌아가지 않아도 되는 사람이 되었어요."
- ♥9 「답장」 (아울라 연구실, 새벽): 아울라가 처음으로 리나에게 답장을 써. 몇 번이나 지우고 다시 써. 배트리에게 배달을 맡기는 교차 장면(교차: 배트리 "주소가 '바람 부는 곳'인데요?").
- ♥10 「떠나는 법」 (물약 교실, 아침) ★최종: 아울라가 주인공에게 다음 학년 심화반 추천서를 줘. "언젠가 너도 여길 떠나겠지. 그게 내가 제대로 가르쳤다는 증거야." 책장이 다 돌아온 『사라진 물약 100선』이 제자리를 찾아. 보상: 물약 힌트 + 지식 보너스.

### 5-5. 맨디 — 정원사 맨드레이크 · 독초 온실

**성격:** 부끄럼쟁이. 놀라면 비명을 질러서(!) 다들 피해. 말할 때 자주 화분 뒤로 숨어.
**좋아함:** 달빛 이슬, 촉촉 이끼, 박하 잎 / **싫어함:** 빨간 독버섯
**상처:** 맨드레이크라서 무섭다, 시끄럽다는 말만 듣고 자랐어. 그래서 장미, 라벤더, 해바라기처럼 "다들 좋아하는 식물"로 바뀌고 싶어 해.
**주제:** 다른 무언가가 되려던 맨드레이크가, 있는 그대로의 자기를 사랑하게 되는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "저, 저기……" | 더듬는 존댓말, 아주 짧음, 자주 숨음 |
| B | "{player} 님" | 존댓말, 식물 이야기를 할 때만 말이 길어짐 |
| C | "{player} 씨" | 편해진 존댓말, 농담을 시도함 |
| D | "{player}" | 밝은 반말, 노래하듯 말함 |

**하트 이벤트**
- ♥1 「비명」 (독초 온실, 아침): 문을 열자마자 비명. 귀를 막고 도망가기(하락), 그대로 서서 기다리기(상승), 같이 소리 지르기(의외로 소폭 상승, 맨디가 웃음을 참음).
- ♥2 「화분 이야기」 (온실, 낮): 온실 식물 하나하나의 이름과 성격을 소개해. 자기 소개 차례가 오자 화분 뒤로 숨어.
- ♥3 「장미가 되고 싶어」 (온실 → 마을 광장 꽃집, 낮): 장미가 되게 해 주는 물약을 같이 구하러 가. 물약을 뿌리자 잎에 가시만 잔뜩 나서 아파해.
- ♥4 「라벤더가 되고 싶어」 (온실, 저녁): 향기를 바꾸는 물약. 이번엔 냄새가 너무 독해져서 온실 벌들이 다 도망가. 맨디가 처음으로 실패를 보고 웃어.
- ♥5 「비명 참기 연습」 (온실 → 호박밭, 낮) ★큰 고비: 비명을 참는 연습을 하러 시끄러운 곳에 가. 짚신이 까마귀에게 놀림받는 걸 보고 둘이 친해짐(교차: 짚신). 연습은 실패하지만 "비명을 질러도 안 도망간 사람은 처음이에요."
- ♥6 「해바라기가 되고 싶어」 (온실, 맑은 날): 마지막 변신 시도. 이번엔 진짜로 잎이 노랗게 물들기 시작하는데, 뿌리가 시들어 가. 주인공이 멈추게 할지, 맨디의 바람대로 계속할지 선택(계속하면 크게 하락하고 위험 연출).
- ♥7 「뿌리」 (온실, 밤): 시든 뿌리를 함께 살려. 맨디가 처음으로 자기 뿌리를 "못생겼다"가 아니라 "따뜻하다"고 말해.
- ♥8 「온실의 밤」 (독초 온실, 폭풍 밤) ★큰 고비: 폭풍으로 온실 유리가 깨지고 독초 가루가 퍼져. 맨디의 비명이 학교 전체를 깨워서 모두를 구해. 아무도 모르게 혼자 울던 맨디가 다음 날 "비명 덕분에 살았다"는 감사 인사를 받으며 처음으로 크게 웃어.
- ♥9 「이름표」 (온실, 아침): 맨디가 자기 화분에 직접 이름표를 붙여. "맨드레이크 맨디. 시끄러움. 그래도 착함."
- ♥10 「맨드레이크의 노래」 (온실 → 마을 광장, 저녁) ★최종: 비명이 아니라 노래로 소리를 내는 법을 익힌 맨디가 광장에서 작은 공연을 해. "다른 꽃이 되지 않아도, 나는 꽤 괜찮은 맨드레이크예요." 보상: 온실 성장 보너스 + 희귀 씨앗.

### 5-6. 짚신 — 꼬마 허수아비 · 호박밭

**성격:** 매일 같은 자리에 서서 까마귀를 쫓기만 해. 왜 사는지, 무슨 의미가 있는지 모르겠다는 말을 덤덤하게 해. 까마귀들은 짚신을 무서워하지 않고 놀리기만 해.
**좋아함:** 빗자루 짚, 호박씨, 해바라기씨 / **싫어함:** 까마귀 깃털
**숨은 사실:** 짚신은 호박밭 주인 할머니가 먼저 떠난 남편의 옷으로 만든 허수아비야. 할머니는 매일 아침 짚신에게 말을 걸어.
**주제:** 대단한 의미가 없어도, 살아 있다는 것 자체가 누군가에게는 귀한 의미일 수 있다는 걸 깨닫는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "누구……" | 덤덤하고 느린 반말, 혼잣말 같음 |
| B | "학생" | 반말, 엉뚱한 질문을 던짐("구름은 왜 서 있지 않아?") |
| C | "{player}" | 반말, 속마음과 허무함을 솔직하게 말함 |
| D | "{player}" | 따뜻해진 반말, 아침 인사를 먼저 함 |

**하트 이벤트**
- ♥1 「서 있는 이유」 (호박밭, 아침): "나는 왜 여기 서 있는 걸까." 대답 없이 옆에 서 있어 주기가 상승.
- ♥2 「까마귀 고민」 (호박밭, 낮): 까마귀들이 짚신 모자에 앉아 놀려. 쫓아 주기(짚신이 더 무력함을 느껴 소폭 하락), 같이 까마귀 흉내 내기, 그냥 들어 주기.
- ♥3 「무서운 표정 연습」 (호박밭, 저녁): 무서운 표정을 연습하지만 짚으로 된 얼굴이라 다 웃는 얼굴이 돼. 웃음 포인트.
- ♥4 「할머니의 아침」 (호박밭, 새벽): 할머니가 짚신에게 말을 거는 걸 처음 엿들어. 날씨, 호박, 무릎 아픈 이야기. 짚신은 "나한테 왜 말을 거는지 모르겠어."라고 해.
- ♥5 「아기 까마귀」 (호박밭 → 낡은 풍차, 비) ★큰 고비: 둥지에서 떨어진 아기 까마귀를 짚신 모자 속에 숨겨 줘. 늘 쫓아내던 까마귀를 품게 된 아이러니. 풍차 처마 밑으로 옮겨 함께 돌보는 이동 연출.
- ♥6 「쓰러진 날」 (호박밭, 폭풍 다음 날): 폭풍에 쓰러진 짚신. "다시 안 세워 줘도 돼. 서 있어도 의미 없으니까." 다시 세울지, 짚신의 말대로 잠시 눕혀 둘지 선택. 할머니가 달려와 맨손으로 짚신을 일으키는 장면이 이어짐.
- ♥7 「옷의 주인」 (할머니 집 마루, 저녁): 할머니가 짚신 옷이 남편 옷이라는 걸 이야기해 줘. "그 사람이 서 있던 자리에 네가 서 있어서, 아침에 밭에 나올 수 있어."
- ♥8 「날아가는 날」 (호박밭, 맑은 아침) ★큰 고비: 다 자란 아기 까마귀가 짚신 모자 위에서 첫 비행을 해. 다른 까마귀들이 이제 짚신을 놀리지 않고 쉬어 가는 자리로 써. "나는 쫓아내려고 서 있는 줄 알았는데."
- ♥9 「밤의 호박밭」 (호박밭, 별 밤): 짚신이 주인공에게 처음으로 고맙다고 해. 의미를 찾았냐는 질문에 "아니. 근데 찾지 않아도 될 것 같아."
- ♥10 「돌아올 자리」 (호박밭, 호박달 축제 아침) ★최종: 축제 날 할머니, 맨디, 아기 까마귀가 모두 짚신 곁에 모여. "나는 누군가 돌아올 자리를 지키고 있었던 거야." 짚신이 주인공에게 할머니가 새로 떠 준 모자를 나눠 줘. 보상: 호박 줍기 경주 보너스 + 허수아비 모자(옷).

### 5-7. 세라 선생님 — 양호 선생님 · 본관 양호실 (사람 NPC, 관리자 수정 가능)

**성격:** 다정하지만 물약 맛에는 무자비해. 쓴 물약을 아무렇지 않게 원샷하고 "맛있는데?"라고 해서 학생들이 무서워해.
**좋아함:** 카모마일, 치유 물약, 유령 해마 차
**숨은 사실:** 학생 때 첫 물약을 만들다 폭발 사고로 미각을 잃었어. 그래서 물약 맛을 전혀 몰라. 아무에게도 말하지 않았어.
**남편:** `{npc.husband}`(기본값 "루카스", 관리자 페이지에서 수정 가능). 요즘 밤늦게 들어오고, 이상한 약초 냄새가 나고, 편지를 숨기고, 돈이 빠져나가. 아울라와 몰래 만난다는 소문까지 돌아.
**진실:** 남편은 세라의 미각을 되찾아 줄 물약을 몰래 연구하고 있었어. 아울라에게 금서 책장을 빌리고(교차: 아울라 ♥8 이후), 맨디에게 뿌리 한 조각을, 캇파에게 달빛 이슬을 얻었어. 결혼 10 주년에 맞추려고.
**주제:** 의심과 서운함 너머에 있던 사랑. 그리고 혼자 숨기던 상처를 함께 나누는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "학생" | 다정하지만 업무적인 존댓말 |
| B | "{player} 학생" | 존댓말, 농담이 늘고 남편 이야기를 슬쩍 함 |
| C | "{player}" | 존댓말과 반말이 섞임, 고민을 털어놓음 |
| D | "{player}" | 친한 언니·형처럼 편한 반말 |

**하트 이벤트**
- ♥1 「쓴 물약」 (양호실, 낮): 감기에 걸린 주인공에게 끔찍한 물약을 주는 세라. 마시기/버리기/세라에게 먼저 맛보게 하기 선택.
- ♥2 「도시락」 (양호실, 점심): 남편이 싸 준 도시락 자랑. 그런데 반찬 간이 엉망인 걸 세라만 모르는 눈치.
- ♥3 「늦은 귀가」 (양호실, 밤): 퇴근하지 않고 남아 있는 세라. 남편이 요즘 늦게 들어온다며 웃어넘기지만 손이 멈춰 있어.
- ♥4 「약초 냄새」 (마을 광장 → 시장, 저녁): 장 보러 가는 길에 남편이 시장 뒷골목에서 맨드레이크 뿌리를 사는 걸 목격해. "맨드레이크는 독으로도 쓰이는데……" 세라의 얼굴이 굳어.
- ♥5 「미행」 (양호실 → 본관 복도 → 도서관 서고, 밤) ★큰 고비: 세라와 함께 남편을 몰래 따라가. 남편이 아울라와 서고에서 속삭이는 걸 보고 세라가 도망치듯 돌아서. 주인공이 붙잡을지, 따라갈지, 남편에게 직접 말을 걸지 선택.
- ♥6 「첫 물약」 (양호실, 비): 세라가 학생 때 첫 물약 사고와 미각을 잃은 일을 처음 고백해. "그래서 쓴 걸 쓰다고 못 해요. 아무 맛이 안 나니까." 위로의 레시피(맛 대신 온도와 향으로 만드는 카모마일 차)를 함께 만들어.
- ♥7 「숨긴 편지」 (세라의 집 거실, 저녁): 집에 초대받은 주인공. 서랍에서 남편의 편지 뭉치가 떨어져. 읽을지 말지 선택(읽으면 하락하지만 정보를 얻고, 안 읽으면 상승).
- ♥8 「다툼」 (세라의 집 → 마을 광장, 밤) ★큰 고비: 세라와 남편이 크게 다퉈. 남편은 "조금만 기다려 달라"는 말만 반복해. 세라는 집을 나와 광장 벤치에 앉아. 주인공이 곁을 지키고, 남편이 뛰어나와 사과하지만 비밀은 끝내 말하지 않아.
- ♥9 「연구실」 (본관 빈 교실, 새벽): 주인공이 남편의 비밀 연구실을 발견해. 칠판 가득 적힌 미각 회복 물약 공식, 실패한 병 수십 개, 세라의 첫 물약 사고 기록. 남편이 주인공에게 비밀을 지켜 달라고 부탁해. 지킬지, 세라에게 말할지 선택(지키면 ♥10 감동 상승, 말하면 ♥10 장면이 달라짐).
- ♥10 「단맛」 (양호실, 결혼 10 주년 저녁) ★최종: 남편이 완성한 물약을 넣은 카모마일 차를 세라에게 건네. 한 모금 마신 세라가 "이게…… 단맛이었구나." 하며 울다 웃어. 그리고 바로 자기 물약을 맛보고 "이걸 학생들한테 먹였다고?" 웃음으로 마무리. 보상: 치유 물약 레시피 개선(맛있는 버전) + 세라의 다정한 평소 대사 추가.

### 5-8. 마들렌 — 과자 교실 제빵사 · 과자 교실 (사람 NPC, 관리자 수정 가능)

**성격:** 손이 크고 목소리도 커. 반죽도 웃음소리도 늘 넘쳐. 조용한 걸 못 견뎌.
**좋아함:** 밀 이삭, 벌꿀, 달토끼 찹쌀떡
**이야기:** 전설의 「호박달 케이크」 레시피를 완성하고 싶어. 마들렌의 스승이자 어머니 같던 늙은 제빵사가 30 년 전 흉년 겨울에 딱 한 번 마을 사람들에게 구워 준 케이크야. 스승은 레시피를 남기지 않고 세상을 떠났어.
**반전:** 레시피의 빠진 재료는 특별한 재료가 아니라 "마을 사람마다 하나씩 가져온 재료"였어. 흉년이라 혼자서는 케이크를 만들 수 없어서, 마을 사람들이 조금씩 나눈 재료로 다 같이 구운 케이크였던 거야. 마들렌이 시끄러운 건 스승이 떠난 뒤의 조용한 부엌이 무서워서야.
**주제:** 혼자 완성하려던 레시피가 사실은 함께 나누는 법이었다는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "거기 학생!" | 크고 활기찬 반말, 일방적으로 시킴 |
| B | "{player}!" | 반말, 수다와 요리 비법을 마구 쏟아냄 |
| C | "{player}" | 목소리가 조금 낮아지고 스승 이야기를 함 |
| D | "우리 {player}" | 다정한 반말, 조용한 순간도 편해함 |

**하트 이벤트(요약 방향)**
- ♥1 「밀가루 폭탄」: 과자 교실에서 밀가루 봉투가 터져 둘 다 하얘짐.
- ♥2 「맛보기 담당」: 실패작을 계속 먹여 봄. 솔직하게 말하기/칭찬하기/몰래 버리기 선택.
- ♥3 「스승의 앞치마」: 벽에 걸린 낡은 앞치마와 스승 이야기의 시작.
- ♥4 「조용한 부엌」: 밤에 불 꺼진 과자 교실에 혼자 앉아 있는 마들렌. 시끄러운 이유를 처음 내비침.
- ♥5 「레시피 노트」 ★큰 고비: 스승의 노트를 함께 찾아 시장 → 마녀의 오두막(스텔라에게 점을 봐 달라고 함, 교차: 스텔라)까지 이동. 노트의 호박달 케이크 쪽은 재료 칸이 비어 있어.
- ♥6~♥7: 재료를 하나씩 추측하며 시도하고 실패. 마을 노인들에게 30 년 전 이야기를 듣는 이동 연출(교차: 짚신의 할머니가 "그때 호박을 가져간 게 나였지").
- ♥8 「빈칸의 뜻」 ★큰 고비: 노인들의 증언이 모여 빈칸의 의미를 깨달아. 마들렌이 처음으로 크게 울어.
- ♥9 「재료 모으기」: 주인공과 함께 NPC들에게 재료를 하나씩 부탁하러 다님(나비의 호박 붕어 비늘 장식, 캇파의 달빛 이슬, 맨디의 박하 잎 등. 해당 NPC 하트가 낮으면 다른 재료로 대체되는 분기).
- ♥10 「호박달 케이크」 ★최종: 호박달 축제 밤, 마을 광장에서 다 같이 케이크를 구워 나눠 먹어. 보상: 호박달 케이크 레시피.

### 5-9. 스텔라 — 점성술사 · 마녀의 오두막 앞 (사람 NPC, 관리자 수정 가능)

**성격:** 신비로운 말투에 늘 의미심장하지만 사실 엄청난 길치. 별자리는 읽는데 지도는 못 읽어.
**좋아함:** 월장석, 별똥별 조각, 오로라 파르페
**이야기:** 별자리에서 "호박달 축제 밤, 별 하나가 떨어진다"는 징조를 봤어. 누군가 크게 다친다는 뜻이야. 처음엔 주인공이 다칠 거라고 생각해서 주인공을 지키려 해.
**전개:** 징조를 막기 위해 위험 요소를 하나씩 없애지만(시계탑 난간, 축제 등불 줄, 무대 기둥) 해석이 자꾸 틀려. 길치처럼 별의 뜻에서도 길을 잃어.
**결말:** 축제 밤, 떨어지는 등불에서 주인공을 밀쳐 낸 스텔라가 대신 다쳐. 별 하나는 스텔라 자신이었어. 주인공이 배트리와 함께 세라에게 달려가 스텔라를 살려. "별은 길을 알려 줄 뿐이고, 걷는 건 우리야."
**메인 스토리 떡밥:** 마지막에 별자리에 아직 설명되지 않는 빈자리가 하나 남아 있다는 걸 언급하고 끝내.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "별의 아이여" | 신비로운 예언체 존댓말, 의미심장한 짧은 말 |
| B | "{player} 님" | 예언체가 자꾸 깨지고 길치가 들통남 |
| C | "{player}" | 꾸밈없는 존댓말, 두려움을 털어놓음 |
| D | "{player}" | 편한 반말, 농담과 진심이 섞임 |

**하트 이벤트(요약 방향)**
- ♥1 「별의 아이여」: 오두막 앞에서 거창한 예언을 하고 돌아서다 길을 잃음.
- ♥2 「길 안내」: 시장까지 데려다 달라는 부탁. 가는 내내 별 이야기.
- ♥3 「징조」: 밤 언덕에서 별자리를 보며 떨어지는 별 징조를 처음 말함.
- ♥4 「주인공 지키기」: 주인공을 졸졸 따라다니며 위험한 걸 다 치움. 웃음 포인트.
- ♥5 「점성술사의 고백」 ★큰 고비: 시계탑 꼭대기로 이동. 예전에 본 징조를 막지 못해 동생이 다친 과거를 고백.
- ♥6 「틀린 해석」: 시계탑 난간을 고쳤는데 징조가 사라지지 않음. 해석이 틀렸다고 좌절.
- ♥7 「밤샘 계산」: 오두막에서 밤새 별자리를 다시 계산. 주인공이 곁에서 도움(마들렌의 야식 교차 가능).
- ♥8 「진짜 뜻」 ★큰 고비: 떨어지는 별이 주인공이 아닐 수도 있다는 걸 깨닫지만, 그게 누구인지는 말하지 않음(스텔라는 자기라는 걸 알게 됨).
- ♥9 「축제 밤」: 호박달 축제. 떨어지는 등불, 스텔라가 주인공을 밀쳐 내고 다침. 배트리와 함께 양호실로 달리는 긴 이동 연출(교차: 배트리, 세라).
- ♥10 「걷는 건 우리」 ★최종: 양호실에서 깨어난 스텔라. 붕대를 감은 채 웃으며 별자리 빈자리 떡밥. 보상: 운세 효과.

### 5-10. 레오 — 사육장 관리인 · 사육장 (사람 NPC, 관리자 수정 가능)

**성격:** 무뚝뚝하고 말이 짧아. 동물 앞에서만 목소리가 녹아내려.
**좋아함:** 염소젖, 달걀, 늪지 추어탕
**이야기:** 늪지에서 주운 알을 품어 부화시킨 아기 용 '콩알'을 키웠어. 어느 날 콩알이 헛간에 불을 내자, 레오는 마법 동물 관리국에 빼앗길까 봐 겁이 나서 크게 혼냈어. 그날 밤 콩알이 사라졌어.
**진실:** 콩알은 혼난 게 무서워서가 아니라, 자기 때문에 레오가 곤란해질까 봐 스스로 떠난 거야. 낡은 풍차에 숨어서 매일 밤 사육장 근처까지 와서 레오를 지켜보고 있었어.
**주제:** 무뚝뚝한 사람이 사랑을 말로 꺼내는 법을 배우는 이야기.

| 단계 | 호칭 | 말투 |
|---|---|---|
| A | "어이" | 아주 짧은 반말, 대답도 단답 |
| B | "학생" | 짧은 반말, 동물 이야기에서만 말이 길어짐 |
| C | "{player}" | 반말, 서툴게 고민을 꺼냄 |
| D | "{player}" | 여전히 짧지만 고맙다, 미안하다를 말로 함 |

**하트 이벤트(요약 방향)**
- ♥1 「단답」: 사육장 일을 도우려 하면 "됐어." 동물에게 말을 거는 다정한 목소리를 엿들음.
- ♥2 「아기 염소」: 아픈 아기 염소를 같이 돌봄. 레오가 처음으로 길게 말함.
- ♥3 「빈 둥지」: 사육장 구석의 큰 둥지와 그을린 자국. "……아무것도 아냐."
- ♥4 「늪지」: 콩알을 처음 주운 늪지로 이동. 알을 품던 이야기.
- ♥5 「콩알」 ★큰 고비: 콩알 이야기와 그날 밤 크게 혼낸 일을 고백. 그을린 헛간까지 같이 가 봄.
- ♥6 「발자국」: 사육장 주변에서 밤마다 생기는 작은 발자국과 사라지는 달걀을 발견.
- ♥7 「잠복」: 밤에 함께 잠복. 콩알 대신 다른 동물이 걸려 허탕. 레오가 "보고 싶다"를 처음 말로 함.
- ♥8 「풍차」 ★큰 고비: 발자국을 따라 낡은 풍차로 이동. 겁먹은 콩알을 찾지만 다가가면 도망쳐. 레오가 서툰 말로 사과하는 장면. 선택에 따라 콩알이 바로 돌아오지 않음.
- ♥9 「말로 하는 법」: 레오가 주인공에게 "미안하다"를 연습함. 웃음 포인트와 진심.
- ♥10 「돌아온 콩알」 ★최종: 레오가 풍차 앞에서 "돌아와. 네가 불을 내도 괜찮아. 내가 막아 줄게." 콩알이 날아와 안김. 보상: 희귀 생물 알(레오가 "이번엔 처음부터 말로 잘 해 줘"라며 건넴).

### 5-11. 사람 NPC 공통(관리자 페이지)

- 관리자 페이지에서 바꿀 수 있는 항목: 이름, 생김새(지금 캐릭터 꾸미기 부품 전부), 서 있는 장소, 좋아하는 선물, 평소 대사, 하트 이벤트 대사 전체, 남편 이름 같은 이야기 속 변수.
- 위 기본값을 처음 넣어 둘 시드 데이터로 저장해.
- 관리자 페이지에 이벤트 대사 편집기를 추가해: 이벤트 목록 → 스크립트 노드 목록(대사, 선택지, 이동 명령)을 표로 보고 수정, 줄 추가·삭제, 미리 보기 재생.
- 관리자가 저장할 때도 4 장의 국어 검사기를 돌려서 경고를 띄워.

## 6. 작업 순서

1. 0 장(코드 파악) 결과를 먼저 요약해서 보여 줘.
2. 대화 스크립트 실행기와 명령(3 장)을 구현하거나 확장해.
3. 호감도 시스템(2 장)을 구현하거나 확장해.
4. NPC 1 명씩 아래 순서로 작성해.
   1. `profile.json`(말투 단계, 일상 대사, 선물 반응)
   2. ♥1~♥10 이벤트 파일 10 개
   3. 검증 스크립트 실행 → 오류 0 개가 될 때까지 수정
   4. 그 NPC 요약 출력(이벤트 제목, 줄 수, 선택지 수, 플래그 목록, 교차 지점)
5. 순서: 나비 → 배트리 → 캇파 → 아울라 → 맨디 → 짚신 → 세라 → 마들렌 → 스텔라 → 레오
6. 10 명이 다 끝나면 교차 장면 점검: 서로 언급하는 대사와 플래그 조건이 실제로 맞물리는지 확인해.
7. 관리자 페이지(5-11) 작업.

## 7. 검증 스크립트 (`scripts/validate_npc.*`)

NPC 데이터를 읽어서 아래를 검사하고 위반 목록을 출력해.

1. **분량:** 이벤트마다 한 경로 기준 90~120 줄, ♥5·♥8·♥10은 110~140 줄. 모든 분기 경로를 각각 세서 가장 짧은 경로도 기준을 넘는지.
2. **선택지:** 이벤트마다 선택지 지점 3~5 개, 상승·유지·하락 보기가 모두 있는지. 모든 `next`가 실제 라벨을 가리키는지.
3. **이동 연출:** 이벤트마다 `move` 또는 `follow`가 1 개 이상인지.
4. **말투 단계:** profile에 A~D 단계 일상 대사가 각각 12 줄 이상인지.
5. **플래그:** NPC마다 분기 플래그가 3 개 이상이고, 설정한 플래그가 이후 이벤트에서 실제로 쓰이는지.
6. **숫자 띄어쓰기:** 정규식으로 숫자 바로 뒤에 단위 명사가 붙은 경우를 모두 잡아.
   `\d+(일|번|째|개|마리|년|명|시|분|초|장|권|살|층|그릇|걸음|골드|주년|군데|송이|잔|병|통|칸|줄|쪽|달|주)` → 0 건이어야 함
7. **문장 부호:** `...`, `…`(한 글자짜리), `?!`, `!!`, `~~`이 0 건인지.
8. **자주 틀리는 표기:** 4-2의 틀린 형태(몇 일, 금새, 왠일, 웬지, 어떻해, 할께, 설레임, 바램, 일부로, 오랫만, 구지, 역활, 희안) 0 건인지. `돼`/`되` 오용 의심 패턴(`되요`, `돼서는 안 되`, `안돼`, `됬`)도 잡아.
9. **사람 NPC 변수:** 사람 NPC 이벤트에 고정된 이름("세라", "루카스" 등)이 직접 들어가지 않고 `{npc.name}`, `{npc.husband}`로 되어 있는지. 성별 단정 표현(그녀, 그는, 아저씨, 아줌마, 언니, 오빠, 형, 누나)이 0 건인지.
10. 위반이 남아 있으면 다음 NPC로 넘어가지 말고 고쳐.

## 8. 마지막 보고

다 끝나면 아래를 보여 줘.
- NPC별 이벤트 제목 목록과 줄 수 표
- 전체 분기 플래그 목록과 쓰이는 곳
- 교차 장면 목록(어느 NPC 이벤트에서 누가 나오는지)
- 검증 스크립트 최종 결과(위반 0 건)
- 내가 직접 읽어 보면 좋을 이벤트 5 개 추천(가장 감동적인 장면 위주)
