# 레이드 「얼음 거인」 기획 (시안)

## 화면
- 보스는 가운데에 서고, 양쪽에 6 명씩 모두 12 명이 서요. 한쪽은 앞열 3 명, 뒷열 3 명이에요.
- 아래에는 「앞쪽 파티 6」 · 「뒤쪽 파티 6」 카드가 3 × 2 로 놓여요.
- 치유·버프는 카드를 누르거나 전투 화면의 사람을 눌러서 대상을 골라요.
- **반대쪽 파티도 대상으로 고를 수 있어요** (정해짐).

## 정할 것 (초안)
- 여는 방법: 관리자가 열기 → 정해진 시간 동안 모여서 시작
- 인원: 최대 12 명 · 모자라면 보스 체력을 인원만큼 줄이기
- 보스 단계: 체력 100~70 % / 70~35 % / 35 % 아래
- 앞뒤 노리기: 큰 기술 전에 화살표로 노릴 쪽을 미리 보여 주기
- 전체 공격 (정해짐): 12 명 모두에게 들어가는 공격
  - 미리 알림: 화면 가장자리가 푸르게 깜빡이고 「얼음 거인이 숨을 크게 들이마셔요....」 + 양쪽 화살표
  - 한쪽 공격보다 한 사람당 피해는 작고, 보호막·막기·치유로 버티는 기술
  - 2 단계부터 가끔, 3 단계에서는 더 자주 써요
  - 바로 뒤에 한쪽 공격이 이어지기도 해서, 치유사가 양쪽을 번갈아 챙겨야 해요
- 보상: 참여 · 피해량 · 치유량 · 막은 양에 따라

## 보스 (정해짐: 2 종)
- 얼음 거인: 하늘색 거울 · 얼음 섬 · 얼어붙은 탑 · 느리고 단단해요 · 「눈보라」로 한쪽을 얼려서 느리게 만들어요
- 불꽃 용: 붉은 거울 · 용암 섬 · 불타는 탑 · 빨라요 · 불꽃 숨결 화상이라 치유사가 바빠요
- 관리자가 레이드를 열 때 둘 중 하나를 골라요 · 보스마다 거울 빛 · 거울 너머 풍경 · 기념품이 달라요
- 보스 그림은 새로 그려요 (지금 몬스터 그림에는 큰 보스가 없어요)

## 피하기 (아직 안 정함 · 추천은 1 + 2)
1. 타이밍 피하기: 줄어드는 원이 고리에 맞을 때 「피하기」 → 완벽 20 % · 조금 어긋남 60 % · 놓침 100 %
2. 같이 막기: 큰 기술 준비 중 끊기 게이지를 다 채우면 기술 취소
3. 자리 고르기: 앞열 · 뒷열 바꾸기

## 정해짐 (11/4): 보스 4 종 · 피하기 1 + 2
- 보스: 얼음 거인 · 불꽃 용 · 그림자 마녀 · 시계탑 골렘 (LPC 부품 조립 tools/iso/lpc/raid_boss_lpc.py → raid_bosses.png · LPC에 없는 얼음 수정 · 시계판 · 톱니만 같은 화풍으로 덧그림)
- 피하기: 타이밍 피하기 + 같이 막기 (끊기 게이지)
- 스킬 (한쪽 / 전체 / 3 단계 큰 기술) · 이펙트 시안 raid_fx.js → raid_fx_sheet.png
  - 얼음 거인: 눈보라 (얼려서 느리게) / 얼음 비 / 빙하 내려찍기
  - 불꽃 용: 불꽃 숨결 (화상) / 불비 / 화산 포효
  - 그림자 마녀: 그림자 손 (붙잡기) / 저주 안개 / 분신 셋 (진짜를 찾아 때려요)
  - 시계탑 골렘: 톱니 날 / 시간 멈춤 (모두 느려짐) / 되감기 (체력 9 % 되돌림)

## 여는 방법 · 횟수 (정해짐)
- 관리자가 열 때만 해요
- 한 사람이 하루에 3 번까지 (자정에 다시 3 번)

## 보상 (제안 · 아직 안 정함)
- 이기면: 골드 1500 · 보스의 문장 2 · 마나석 2 · 거울 조각 10 · 심장석 15 % 확률
- 지면: 깎은 보스 체력만큼 나눠서 (예: 60 % 깎으면 위 보상의 절반 × 0.6)
- 하루 첫 승리: 거울 조각 +10
- 활약 별 (순위 없음 · 기준만 넘으면 누구나): 딜 · 치유 · 막기 · 피하기 · 끊기 · 별 하나에 거울 조각 +2
- 보스 기념품: 그 보스를 처음 이기면 확정 · 그다음은 5 % 확률
- 거울 상점 (거울 조각): 보스 망토 · 왕관 꾸미기 · 거울 가구 · 강화 재료 교환

## 보상 방식 바꿈 (11/4 · 제안)
- 사람마다 따로 뽑아요 (같은 판이어도 받는 게 달라요) · 끝나면 상자를 열어 각자 뽑기
- 뽑기 횟수: 이기면 3 번 · 지면 깎은 체력 30 % 마다 1 번 (최대 2 번) · 활약 별 2 개마다 +1 번
- 난이도 (관리자가 열 때 고름): 보통 · 어려움 · 악몽
  - 보스 체력·공격: 1 배 · 1.6 배 · 2.4 배 / 피하기 타이밍 고리: 보통 · 좁게 · 더 좁게
  - 뽑기 표가 좋아져요 (아래 확률은 보통 / 어려움 / 악몽)
    - 탐사 골드 500~1500: 60 / 40 / 25 %
    - 보스의 문장 1~3: 25 / 30 / 30 %
    - 심장석 1: 8 / 15 / 22 %
    - 거울 조각 5~15: 7 / 12 / 15 % (어려움 ×1.5 · 악몽 ×2)
    - 보스 기념품: 0 / 3 / 8 % (보통은 처음 이길 때만 확정)
- 보스 기념품 쓸모 (11/4 바꿈): 장신구 칸에 하나 차기 · 능력 하나씩 · 칭호 없음
  - 얼음 왕관: MP 사용량 −7 / −10 / −13 / −16 / −19 % (★1~5)
  - 용 비늘 망토: 공격·마법 +5 / +8 / +11 / +14 / +17 %
  - 그림자 모자: MP 회복량 +10 / +15 / +20 / +25 / +30 %
  - 톱니 시계 목걸이: 행동 속도 +3 / +5 / +7 / +9 / +11 %
  - 같은 기념품을 또 얻으면 별 강화 (★n → ★n+1 에 n 개)
