# 「첫눈의 소원」 · 실제 구현 (시안 1에서 바뀐 것 반영)

## 0. 한 줄
첫눈 오는 밤, 하늘에서 소원 쪽지가 눈처럼 내려요. 주워서 남의 소원을 응원하고, 내 소원도 날려 보내요. 마지막 밤에는 응원 받은 소원들이 별자리가 되어 밤하늘에 남아요.

## 1. 열고 닫기
- 관리자가 「이벤트 시작」을 누르면 열리고, 「이벤트 끝내기」를 누를 때까지 계속돼요.
- 열려 있는 동안 날씨는 눈. 등불 마을 광장 · 교정 · 기숙사 거리에 쪽지가 하루 여러 번 내려요.
- 관리자가 끝내면 「첫눈 별자리」 연출이 모두에게 한 번 나오고, 모든 소원과 응원 글이 일지에 공개돼요.

## 2. 쪽지 줍기와 응원
- 하늘에서 쪽지가 하나둘 내려와 땅에 반짝이며 떨어져요. 누르면 주워요.
- 쪽지를 펼치면 다른 학생이 쓴 소원이 보여요. 이름은 절대 안 보여요. 「어느 학생의 소원」.
- 「★ 응원하기」를 누르면 별 하나가 하늘로 날아가요. 응원 한마디(50 자까지, 안 써도 돼요)를 같이 달 수 있어요. 같은 소원은 한 번만.
- 응원 글은 이벤트가 끝날 때까지 아무도 못 봐요 (끝나면 소원 주인과 모두가 볼 수 있어요).
- 하루에 주울 수 있는 쪽지: 10 장. 내 소원은 내 화면에 안 떨어져요.

## 3. 내 소원 쓰기
- 「일지 → 첫눈의 소원」에서 소원을 써요. 40 자까지 · 한 사람 하나 (끝나기 전까지 고칠 수 있어요).
- 「날려 보내기」를 누르면 쪽지가 접혀서 하늘로 올라가 별이 돼요.
- 누군가 응원하면 「누군가 내 소원을 응원했어요 ★ 4」 알림이 떠요. 별이 많을수록 내 별이 밝아져요.

## 4. 안전 (학교라서 꼭)
- 소원과 응원 글은 바로 올라가고, 관리자 카드에서 누가 썼는지 보고 「숨기기」 할 수 있어요.
- 반 친구 닉네임, 욕설, 전화번호·주소 같은 글은 쓰는 순간 막아요 (「이름이나 개인 정보는 쓸 수 없어요」).

## 5. 마지막 밤 「첫눈 별자리」
- 화면이 밤하늘로 바뀌고, 응원 받은 소원들이 별이 되어 하나씩 켜져요.
- 별들이 선으로 이어지며 눈송이 모양 별자리가 돼요.
- 소원 글귀가 별 옆에 잠깐씩 떠올랐다 사라져요 (숨기지 않은 소원 중 무작위 8 개).
- 「첫눈 별자리 · 응원 받은 소원 ○ 개 · 응원 별 ○ 개」.
- (나중에 할 것) 겨울 동안 「별 보는 언덕」 밤하늘에 이 별자리 남기기.

## 6. 보상
- 방 가구 「소원 유리병」: 내가 응원한 소원 쪽지들이 별빛으로 담겨 반짝여요. 응원한 수만큼 별이 많아져요.
- 말풍선 꾸미기 「눈송이 말풍선」
- 응원을 10 번 넘게 한 학생: 이름표 꾸미기 「별지기 이름표」
- (소원 유리병 가구는 아직 그림 작업 전)

## 7. 연출과 소리
- 쪽지는 진한 테두리 · 하얀 종이 · 하늘색 접힌 선 · 분홍 점, 은은한 빛 (픽셀).
- 소리: 눈 오는 밤 오르골 (직접 만든 가락) · 쪽지 떨어질 때 방울 · 펼칠 때 종이 소리 · 응원 별 올라가는 소리 · 별자리 켜지는 소리.

## 8. 관리자
- 이벤트 탭 접는 카드: 시작 · 끝내기, 소원 목록(쓴 학생 이름 · 응원 수 · 숨기기), 소원마다 응원 글(쓴 학생 이름 · 숨기기).
- 학생마다 누가 뭘 썼는지는 관리자만 볼 수 있어요.

## 9. 저장 (만들 때 참고)
- `wish/ctl = { open, id, at, sky 별자리 시각 }`
- `wish/list/<id> = { u 쓴 사람, t 글, ok 허락, n 응원 수, at }` (학생은 ok 인 것만 읽어요 · u는 관리자만)
- `me.wish = { ev, id 내 소원, got { 날: [주운 id] }, ch { 응원한 id: 1 }, seen 별자리 봄 }`
